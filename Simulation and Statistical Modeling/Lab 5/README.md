# Лабораторная работа №5 — Сети Петри

Приложение моделирует обе сети Петри из методички:

- `Схема 1`: позиции `p1...p5` и переходы `a...d`;
- `Схема 2`: позиции `p1...p6` и переходы `t1...t4`.

В интерфейсе доступны ручное и автоматическое срабатывание переходов, сброс к начальной маркировке, просмотр текущей маркировки, граф достижимых маркировок, проверка достижения заданной маркировки и поиск параллельных переходов.

## Сборка в Windows

Из каталога `Lab 5`:

```powershell
cmake -S . -B build -G Ninja
cmake --build build --target Lab5 --parallel 4
.\build\Lab5.exe
```

Если FLTK уже подключён в соседней лабораторной, CMake автоматически использует `Lab 1/external/fltk`.
