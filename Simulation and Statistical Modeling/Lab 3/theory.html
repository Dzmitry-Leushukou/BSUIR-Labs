Что происходит в лабораторной

Основное объяснение читается сверху вниз. Подробные вычисления раскрываются под соответствующим примером.

1. Программа много раз получает два числа

Один запуск генератора даёт пару: например, X = 0,3 и Y = −0,7. Эту пару можно нарисовать как точку на плоскости: 0,3 по горизонтали, −0,7 по вертикали.

Сгенерировали 10 000 пар — получили 10 000 точек. Это наша выборка. Число 10 000 — её размер.

Точки появляются по заданному правилу. Это правило называется законом распределения. В непрерывной части оно записано формулой плотности, в дискретной — таблицей вероятностей.

Задача лабы: сгенерировать данные по этому правилу, посчитать их среднее и разброс, построить графики и выяснить, связаны ли X и Y.

2. Непрерывный случай: значения могут быть дробными

Например, X может получиться 0,3, −1,24 или 0,008. Для номера 17 в списке задан вариант 8. Его формула:

f(x, y) = e−x²−y² / π.

Она говорит: ближе к нулю точки появляются чаще, далеко от нуля — реже. Поэтому 3D-график похож на холм с вершиной над точкой (0, 0).

Что такое плотность

Выбери на плоскости маленький квадрат. Чем выше над ним поверхность, тем больше точек обычно попадает в такой квадрат.

Чтобы получить вероятность, учитывают и высоту, и размер квадрата. Для очень маленького квадрата:

Вероятность ≈ плотность × площадь квадрата.

В центре плотность равна 1/π ≈ 0,318. У маленького квадрата около центра со стороной 0,1 площадь равна 0,01. Вероятность попасть в него примерно 0,318 × 0,01 = 0,00318, то есть 0,318%.

Для большой области высота заметно меняется, поэтому её учитывают по маленьким частям и складывают их вклад. Это и делает интеграл.

Маргинальная плотность: смотрим только на X

Представь список всех полученных пар. Закрой столбец Y. Остались только значения X. Нас интересует, какие из них встречаются чаще.

Это и описывает маргинальная плотность X. Чтобы получить её из общей формулы, нужно учесть все возможные Y. На языке математики — проинтегрировать по y:

fX(x) = ∫−∞∞ f(x, y) dy = e−x² / √π.

Почему именно по y: X оставляем, а все варианты Y объединяем. Для плотности Y делаем наоборот: интегрируем по x.

Откуда в ответе √π
e−x²−y² = e−x² · e−y²fX(x) = (e−x²/π) · ∫−∞∞ e−y² dy= (e−x²/π) · √π = e−x²/√π.

При вычислении по y множитель e−x² не меняется, поэтому его выносим перед интегралом. Оставшийся интеграл — известный гауссов интеграл, равный √π. Аналогично fY(y) = e−y²/√π.

Условная плотность: Y уже известен

Теперь другой вопрос: если нам сообщили Y, изменились ли ожидания относительно X? Распределение X при известном Y называется условным.

Для него делим совместную плотность на плотность того, что уже известно:

fX|Y(x | y) = f(x, y) / fY(y) = e−x²/√π.

В нашей модели ответ совпал с обычной плотностью X. Какое бы Y ни сообщили, распределение X осталось прежним. Это означает независимость X и Y.

Как сократилось выражение и зачем делить
[e−x²e−y²/π] / [e−y²/√π]
= e−x² · √π/π = e−x²/√π.

Сократили одинаковые e−y². Деление нужно, чтобы у распределения X при выбранном Y общая вероятность снова равнялась 1. Для обратного условия fY|X(y | x) = e−y²/√π.

3. Дискретный случай: выбираем из 0, 1 и 2

Здесь разрешены отдельные значения. Мы сами задали таблицу:

X ↓ / Y →012Сумма строки
00,050,100,050,20
10,100,200,100,40
20,050,150,200,40
Сумма столбца0,200,450,351

Число 0,10 в строке X = 1 и столбце Y = 2 означает: вероятность получить пару (1, 2) равна 10%. При большом числе запусков примерно десятая часть пар будет такой. Точное количество заранее неизвестно.

Маргинальная вероятность: сколько всего случаев с X = 1

У X = 1 есть три варианта Y. Складываем их вероятности:

P(X = 1) = 0,10 + 0,20 + 0,10 = 0,40.

Получили 40%. Это сумма строки, она же «итог строки». Для Y = 1 складываем столбец: 0,10 + 0,20 + 0,15 = 0,45. Никакого отдельного сложного действия за словом «маргинальная» здесь нет.

Условная вероятность: известно, что X = 1

Оставляем только выделенную строку. Общая вероятность этой строки — 0,40. Внутри неё вероятность пары (1, 2) — 0,10.

P(Y = 2 | X = 1) = 0,10 / 0,40 = 0,25 = 25%.

Среди случаев, где X = 1, четверть имеет Y = 2. Делим на 0,40, потому что теперь рассматриваем только эту часть всех случаев.

Вертикальная черта читается «при условии». Если известно Y = 2, делим уже на сумму столбца 0,35: P(X = 1 | Y = 2) = 0,10/0,35 ≈ 28,6%.

Проверим связь: без дополнительной информации Y = 2 имеет вероятность 35%. Узнали X = 1 — она стала 25%. Знание X изменило вероятность Y, поэтому в этой матрице X и Y зависимы.

4. Как проверяется независимость по полученным данным

Из формулы или матрицы мы знаем, как устроена модель. Теперь нужно проверить, что показывает случайная выборка. В ней даже при независимости возникают случайные перекосы.

H₀ — наше проверяемое предположение: «X и Y независимы». H₁ — другой вариант: «они зависимы».

Сначала сравниваем «получилось» и «ожидалось»

Допустим, сгенерировали 60 пар. Это небольшой учебный пример для объяснения теста:

Y = 0Y = 1Всего
X = 081220
X = 1152540
Всего233760

Здесь стоят количества пар. Например, 8 раз получили X = 0 одновременно с Y = 0.

Случаев с X = 0 — всего 20. Случаев с Y = 0 — всего 23 из 60. Если X и Y независимы, среди этих 20 случаев должна быть примерно такая же доля Y = 0:

Ожидаемое количество = 20 × (23/60) ≈ 7,67.

Получили 8, ожидали 7,67. Так считаем ожидаемое количество для каждой клетки.

Общая формула ожидаемого количества
Eij = (сумма строки i × сумма столбца j) / n.

Индексы i и j — номера строки и столбца, n — общее количество пар. Буква E обозначает ожидаемое количество. Оно может быть дробным: это ориентир для сравнения.

χ²: одно число для всех расхождений

Для каждой клетки выполняем три действия: вычитаем ожидаемое из фактического, возводим разницу в квадрат и делим на ожидаемое. Затем складываем результаты:

χ² = сумма [(получилось − ожидалось)² / ожидалось].

Для первой клетки: (8 − 7,67)²/7,67 ≈ 0,0145. Квадрат нужен, чтобы положительные и отрицательные расхождения не уничтожили друг друга.

Для всей учебной таблицы χ² ≈ 0,0353. Это маленькое расхождение. Осталось понять, насколько оно обычно при независимости.

p-value: могло ли такое расхождение возникнуть случайно

Мысленно допускаем, что X и Y действительно независимы. p-value — вероятность получить такое же или ещё большее χ² при этом допущении.

Для учебной таблицы p ≈ 0,851. Это означает, что подобное или большее расхождение при независимости вполне обычно. Оснований отвергнуть её нет.

Заранее выбираем порог, обычно 0,05. Он называется уровнем значимости α:

  • p меньше 0,05: расхождение слишком необычно для независимости → отвергаем H₀.
  • p не меньше 0,05: недостаточно оснований отвергнуть H₀.

0,05 задаёт допустимую вероятность ошибочно отвергнуть истинную H₀ для корректного теста. p = 0,851 не означает, что H₀ верна с вероятностью 85,1%.

Как программа находит p-value и зачем df

При независимости χ² приближённо подчиняется известному распределению. Оно зависит от числа степеней свободы df. Для таблицы с r строками и c столбцами:

df = (r − 1)(c − 1).

При фиксированных суммах последняя клетка строки определяется остальными. Аналогично для столбцов. Для таблицы 2 × 2 остаётся df = 1.

Программа передаёт χ² и df в SciPy: chi2.sf(χ², df). Функция вычисляет площадь справа от нашего χ² на кривой соответствующего распределения. Эта площадь и есть p-value.

Проверяем именно H₀, потому что при её выполнении известен закон χ². H₁ включает много разных зависимостей. Мы ищем достаточно сильное противоречие H₀; отсутствие такого противоречия не доказывает независимость.

В нашей программе при исходных настройках — 10 000 пар, seed = 17, 15 интервалов:
непрерывный случай: p ≈ 0,870 → независимость не отвергается;
начальная матрица ДСВ: p ≈ 6,50 × 10−155 → независимость отвергается.

Последнее число очень маленькое, но положительное. Выборка обнаружила зависимость, которая уже есть в нашей матрице.

Для непрерывных данных программа сначала группирует значения по интервалам. При слишком маленьких ожидаемых количествах приближение χ² ненадёжно; простой ориентир — не меньше 5 в каждой клетке.

5. Среднее, дисперсия и корреляция

Среднее — складываем значения и делим на их количество. Дисперсия — насколько сильно значения разбросаны вокруг среднего. Для неё считаем квадраты отклонений: большие отклонения дают больший вклад.

Корреляция описывает линейную связь: склонен ли Y расти вместе с X, уменьшаться или выраженной линейной связи нет. Она лежит от −1 до 1. Ковариация — исходная мера совместного изменения; делением на стандартные отклонения её переводят в корреляцию.

В таблице приложения «Теория» вычисляется из закона распределения. «Оценка» вычисляется по сгенерированным данным. Поэтому они обычно немного различаются.

ХарактеристикаНепрерывная модельНачальная матрица ДСВ
Среднее X01,20
Среднее Y01,15
Дисперсия X0,500,56
Дисперсия Y0,500,5275
Корреляция0≈ 0,221
Откуда 0 и 0,5 в непрерывной модели

Плотность симметрична относительно нуля: положительные и отрицательные значения равной величины встречаются одинаково часто. Поэтому среднее равно 0.

M(X) = ∫−∞∞ x fX(x) dx = 0.
D(X) = M(X²) − M(X)².

Второй момент — среднее квадратов значений. Для нашей плотности:

M(X²) = (1/√π) ∫−∞∞ x²e−x² dx = 1/2.

Если спросят про производную: производная e−x² равна e−x², умноженному на производную показателя −x², то есть −2xe−x².

Благодаря этому интегрирование по частям даёт:

∫−∞∞ x²e−x² dx
= [−xe−x²/2]−∞∞ + (1/2)∫−∞∞ e−x² dx = √π/2.

Граничное выражение стремится к нулю. Делим √π/2 на √π, получаем 1/2. Среднее равно нулю, поэтому дисперсия тоже равна 1/2. Для Y расчёт такой же.

Компоненты независимы, поэтому ковариация и корреляция равны нулю. В общем случае нулевая корреляция сама по себе независимость не доказывает.

Как получены числа для дискретной матрицы

Среднее — каждое значение умножаем на его вероятность и складываем:

M(X) = 0·0,20 + 1·0,40 + 2·0,40 = 1,20.
M(Y) = 0·0,20 + 1·0,45 + 2·0,35 = 1,15.

Для дисперсии сначала аналогично считаем среднее квадратов, затем вычитаем квадрат среднего:

D(X) = (0²·0,20 + 1²·0,40 + 2²·0,40) − 1,20² = 0,56.
D(Y) = (0²·0,20 + 1²·0,45 + 2²·0,35) − 1,15² = 0,5275.

Для ковариации берём каждую пару из матрицы, перемножаем X, Y и вероятность этой пары, затем складываем. Клетки с X = 0 или Y = 0 дают ноль:

M(XY) = 1·1·0,20 + 1·2·0,10 + 2·1·0,15 + 2·2·0,20 = 1,50.
Cov(X,Y) = M(XY) − M(X)M(Y) = 1,50 − 1,20·1,15 = 0,12.
ρ = 0,12 / √(0,56·0,5275) ≈ 0,221.
Как считать по выборке и почему делим на n − 1

Для среднего складываем все X и делим на n. Обозначим результат x̄. Затем:

Дисперсия X = сумма (X − x̄)² / (n − 1).
Ковариация = сумма [(X − x̄)(Y − ȳ)] / (n − 1).
Корреляция = ковариация / √(дисперсия X × дисперсия Y).

Среднее уже подстроено под эту же выборку. Поэтому отклонения от него в сумме равны нулю: последнее отклонение определяется остальными. Например, у чисел 2 и 4 среднее 3: если первое отклонение −1, второе обязано быть +1.

Из-за такой подстройки деление на n занижает дисперсию в среднем по многим выборкам. Деление на n − 1 исправляет это занижение.

6. Доверительный интервал: насколько неточна оценка

Допустим, по выборке получили дисперсию 0,49. Из другой случайной выборки получится немного другое число. Интервал показывает диапазон значений, согласующихся с данными с учётом этой случайности.

Например, получился [0,47; 0,52]. Теоретические 0,50 попадают внутрь — наша оценка согласуется с теорией по этому критерию. Такой пример поясняет столбец «H₀: теория верна».

Как программа получает границы: 300 раз случайно набирает пары из уже имеющейся выборки, разрешая одной паре повторяться. Каждый раз заново считает нужную характеристику. Этот способ называется бутстрэпом.

По разбросу повторных оценок выбираются нижняя и верхняя границы. Для уровня 95% оставляют по 2,5% с каждого края. Границы приблизительные.

Точная последовательность в нашей реализации

Для скорости каждый повтор использует не больше 2000 пар. Из повторной оценки вычитается исходная оценка. Разность умножается на √(размер повтора / размер исходной выборки), чтобы приближённо учесть разные размеры.

Из этих разностей берутся границы 2,5% и 97,5%, затем прибавляются к исходной оценке. Например: 0,49 + (−0,02) = 0,47 и 0,49 + 0,03 = 0,52.

Уровень 95% описывает процедуру: при многократном повторении исследования корректно построенные интервалы должны содержать истинное значение примерно в 95% случаев.

7. Что говорить по графикам

Гистограммы X и Y: столбцы показывают, какие значения чаще получались в выборке. Линия показывает ожидаемое распределение. Сравниваем форму и расположение: согласуется ли результат генерации с заданным законом.

Непрерывный 3D: каждая точка основания задаёт пару X и Y. Высота — плотность. Теоретическая поверхность гладкая, а выборочная неровная из-за случайности и группировки по ячейкам. Для маленькой ячейки вероятность примерно равна высоте, умноженной на площадь основания.

Дискретный 3D: высота для конкретной пары — её вероятность или доля появлений в выборке. Соединяющая поверхность помогает видеть форму; промежуточные значения X и Y генератор не создаёт.

Похожесть графиков подтверждает согласие с заданным распределением. Вывод о независимости делается отдельно, как описано в пункте 4.
