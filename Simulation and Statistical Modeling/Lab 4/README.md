# Лабораторная работа 4

Приложение решает вариант 17: оператор обслуживает `n` станков, которые отказывают с интенсивностью `lambda`, а ремонт выполняется с показательной длительностью `tобсл`.

Состояние `k` означает, что неисправны `k` станков (`k = 0...n`). Переходы имеют интенсивности:

- `k -> k + 1`: `(n - k) * lambda`;
- `k -> k - 1`: `k * mu`, где `mu = 1 / tобсл`.

Программа вычисляет финальные вероятности `p_k` и характеристики:

- `A` — среднее число ремонтов в единицу времени;
- `w` — среднее число неисправных станков;
- `R` — среднее число станков в очереди;
- `Pзан` — вероятность занятости оператора.

## Сборка

Из этой папки:

```text
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build --parallel 4
```

Исполняемый файл: `build/Lab4.exe`.

Параметры вводятся в часах: `lambda` — `1/ч`, `tобсл` — часы.
