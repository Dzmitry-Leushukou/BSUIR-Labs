
# Task 5 — Надёжная загрузка файла по URL

## Запуск
```bash
python3 -m url_fetcher.cli "https://example.com/file.pdf" "./downloads" --retries 3 --timeout 20
```
Опции:
- `--name` — задать имя файла вручную;
- `--retries` — повторы при временных ошибках (HTTP 5xx/сетевые);
- `--timeout` — таймаут запроса;
- `--chunk` — размер блока записи.

Особенности надёжности:
- Проверка доступности папки и её автоматическое создание;
- Выбор имени: `--name` → `Content-Disposition` → сегмент пути URL → `download`;
- Обезвреживание имени файла (безопасные символы), недопуск скрытых имён;
- Дедупликация имени (если файл уже есть — `name (1).ext` и т.д.);
- Скачивание во временный файл и **атомарное** переименование;
- Обработка редиректов (стандарт urllib), таймауты, **экспоненциальный backoff** и ретраи для 5xx/сетевых ошибок;
- Понятные сообщения об ошибках и коды выхода.
