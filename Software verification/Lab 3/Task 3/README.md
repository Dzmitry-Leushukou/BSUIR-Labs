
# Task 3 — Площадь прямоугольника (S = a*b)

Надёжная консольная программа, принимающая **длину** и **ширину** из командной строки и печатающая площадь.
- Поддерживает десятичные числа с точкой **или запятой** (`2.5` или `2,5`), а также экспоненты (`1e3`).
- Не допускает отрицательные значения.
- Использует `decimal.Decimal` для высокой точности.
- В случае ошибки печатает понятное сообщение в `stderr` и завершает работу с кодом `1`.

## Запуск
```bash
python -m rect_area.cli 3 4
# -> 12

python -m rect_area.cli 2,5 4
# -> 10
```

Опционально:
```bash
python -m rect_area.cli 1.2345 2 --precision 2
# -> 2.47
```
