# People Age App (Консольная программа)

## Запуск
Из корня проекта:
```bash
python3 -m people_app.cli
```
Далее вводите людей (одна строка = один человек) в формате:
```
Имя Фамилия Возраст
```
Пустая строка завершает ввод.

Вывод:
- Список людей: `Фамилия Имя Возраст` (в порядке ввода)
- Последняя строка: `min max avg` (средний возраст с точностью до сотых)

## Тесты
```bash
python3 -m unittest discover -s tests -p "test_*.py"
```
