Лабораторная работа № 7

Эль-Гамаль на эллиптической кривой

Шифрование прибавляет к точке сообщения случайную точку. Закрытый ключ позволяет вычислить и убрать эту добавку. Ниже — откуда берутся ключи, зачем нужны две точки шифротекста и почему восстанавливаются исходные байты.

Алгоритм по шагам

Заранее заданы кривая E, базовая точка P и её простой порядок q. Умножение d·P даёт точку; сложение и вычитание ниже выполняются по правилам кривой. Координаты считаются по модулю p.

1. Создаём ключи один раз, независимо от сообщения

Выбираем случайное целое d: 1 ≤ d < q
Вычисляем точку Q = d·P

Закрытый ключ — число d. Открытый ключ — точка Q = (xQ, yQ). Для каждого нового блока ключи заново не создаются. Отправителю передаём Q; d остаётся у получателя.

2. Представляем блок сообщения точкой

Берём блок B длиной n: 1 ≤ n ≤ 30 байтов
Читаем его как целое число m старшим байтом вперёд

Перебираем t от 0 до 255:
    x = 256·m + t
    u = (x³ + a·x + b) mod p
    y = u^((p + 1)/4) mod p
    Если y² mod p = u, принимаем M = (x, y) и заканчиваем перебор

M — точка исходного сообщения. t — служебный байт для поиска точки; это не ключ. Если подходящего t нет, кодирование завершается ошибкой. Длина блока n известна при восстановлении из общей исходной длины сообщения.

3. Шифруем блок открытым ключом Q

Сначала проверяем Q: точка конечна, её координаты допустимы, она лежит на кривой и qQ = O. Затем:

Выбираем новое случайное целое k: 1 ≤ k < q

C₁ = k·P        — первая точка шифротекста
S  = k·Q        — маскирующая точка
C₂ = M + S      — вторая точка шифротекста

Если C₂ = O, выбираем новое k и повторяем вычисления C₁, S и C₂. M и ключи сохраняются. Для каждого следующего блока тоже выбирается новое k.

Пара (C₁, C₂) — шифротекст блока. Это две точки, каждая со своими координатами x и y. Получателю передаём эти пары в порядке блоков и исходную длину сообщения. Числа d и k и маскирующую точку S не передаём.

4. Расшифровываем закрытым ключом d

Проверяем 1 ≤ d < q. Точки C₁ и C₂ должны быть конечными и лежать на кривой; дополнительно требуется qC₁ = O. Затем:

S′ = d·C₁       — восстанавливаем маскирующую точку
M  = C₂ − S′    — восстанавливаем точку сообщения

Это работает, потому что:

S′ = d·C₁ = d·(k·P) = k·(d·P) = k·Q = S
M  = (M + S) − S

C₁ нужна, чтобы получить S через закрытый ключ. C₂ содержит сообщение с добавленной S. По отдельности C₁ не содержит исходный блок, а из C₂ без S нельзя непосредственно восстановить M.

5. Возвращаем точку в байты

Если M = O, отклоняем результат
Получаем обычную x-координату точки M
m = ⌊x(M)/256⌋  — отбрасываем служебный байт t

Проверяем: 0 ≤ m < 2²⁴⁰
Записываем m в 30 байтов старшим байтом вперёд с ведущими нулями
Берём последние n байтов — получаем исходный блок B

Повторяем расшифрование для всех пар точек, объединяем блоки в прежнем порядке и получаем исходное сообщение. Далее подробнее разобраны операции и условия, используемые в этих шагах.

1. Что такое точки кривой и как с ними работать

В этой задаче эллиптическая кривая — множество пар целых чисел (x, y), удовлетворяющих уравнению:

y² ≡ x³ + a·x + b (mod p)

Здесь p — заданное простое число, a и b — заданные коэффициенты. Запись «mod p» означает, что берётся остаток от деления на p. Например, 20 mod 17 = 3. Координаты лежат в диапазоне от 0 до p−1. Чтобы проверить точку, достаточно подставить её координаты в обе части уравнения и сравнить остатки.

p задаёт конечное поле: сложение, вычитание и умножение координат выполняются с приведением результата по модулю p. Для любого ненулевого элемента существует обратный, поэтому в формулах точек можно выполнять модульное деление. Кривая должна быть невырожденной: 4a³ + 27b² ≠ 0 (mod p).

Кроме обычных точек есть специальная точка O — точка на бесконечности. Она играет роль нуля при сложении: A + O = A.

Сложение и умножение на число

Две точки складываются по формулам кривой. Их координаты не складывают по отдельности. Для разных точек A = (x₁, y₁) и B = (x₂, y₂), у которых x₁ ≠ x₂:

λ = (y₂ − y₁) · (x₂ − x₁)⁻¹ mod p
x₃ = (λ² − x₁ − x₂) mod p
y₃ = (λ · (x₁ − x₃) − y₁) mod p
A + B = (x₃, y₃)

Обозначение z⁻¹ — обратное число по модулю p: z·z⁻¹ mod p = 1. Оно заменяет деление. Например, обратное к 3 по модулю 17 равно 6, поскольку 3·6 mod 17 = 1.

При сложении точки с самой собой выполняется удвоение: в тех же формулах берут λ = (3x₁² + a)·(2y₁)⁻¹ mod p. Если y₁ = 0, результат удвоения — O.

Умножение точки на целое число — повторное сложение. Например, 3P = P + P + P. Для больших чисел используются удвоения и сложения по битам множителя: 13P = 8P + 4P + P. Результатом остаётся точка.

При умножении на число программа начинает с результата R = O и текущей точки A = P. Биты множителя k просматриваются от младшего к старшему. Если текущий бит равен 1, выполняется R = R + A; перед переходом к следующему биту точка A удваивается. Так вычисляется kP за число шагов, пропорциональное длине k в битах.

Для вычитания нужна противоположная точка: −A = (x₁, −y₁ mod p). Она имеет ту же x-координату и противоположную y-координату. Поэтому A + (−A) = O, а A − B = A + (−B).

Параметры, общие для отправителя и получателя

ОбозначениеСмысл
p, a, bЗадают поле координат и уравнение кривой.
PЗаранее выбранная базовая точка. От неё вычисляются ключи и первая точка шифротекста.
qПорядок P — наименьшее положительное число, для которого qP = O. Секретные числа выбираются от 1 до q−1.

p и q используются для разных действий. По модулю p считаются координаты точек. q задаёт диапазон секретных множителей и цикл кратных базовой точки: (k + q)P = kP. Кратные P образуют подгруппу {O, P, 2P, …, (q−1)P}. У выбранной кривой вся группа содержит 4q точек; произвольная точка сообщения M не обязана входить в подгруппу P.

Строчная p — число, заглавная P — точка. В программе используются готовые параметры кривой TC26 256-paramSetA; при создании ключей новая кривая не генерируется. Все параметры кривой открыты.

2. Откуда берутся ключи

Получатель выбирает случайное целое число d и умножает на него базовую точку P:

1 ≤ d < q
Q = dP

d — закрытый ключ, Q — открытый ключ. d является числом, Q — точкой с координатами x и y. Для новой пары ключей выбирается новое d; параметры p, a, b, P и q сохраняются.

Вычислить Q по известному d легко. Обратная задача — найти d по P и Q — называется задачей дискретного логарифмирования на эллиптической кривой. Для выбранных больших параметров эффективного классического способа её решения не известно.

Для выбора d программа получает 32 байта от системного генератора случайных чисел BCryptGenRandom и интерпретирует их как 256-битное целое. Если d = 0 или d ≥ q, получает новые байты. Такой отбор даёт равномерное распределение в диапазоне 1…q−1. Число k при шифровании выбирается тем же способом, независимо от d.

Отправитель получает Q и использует его для шифрования. Закрытый ключ d ему не нужен. Одна пара ключей может использоваться для разных сообщений.

Перед использованием открытого ключа проверяют: Q ≠ O; 0 ≤ x(Q), y(Q) < p; y(Q)² ≡ x(Q)³ + ax(Q) + b (mod p); qQ = O. Проверка уравнения отсекает пары координат, не являющиеся точками кривой. Проверка qQ = O отсекает точки вне нужной подгруппы. Поскольку q простое и Q ≠ O, прошедшая эти проверки точка имеет порядок q.

3. Как сообщение становится точкой

В формулах Эль-Гамаля сообщение должно быть точкой. Поэтому сначала выполняется обратимое кодирование байтов. Обозначим исходный блок байтов B, число из этих байтов — m, а точку, в которую он преобразуется, — M.

В программе блок содержит n байтов, 1 ≤ n ≤ 30. Его байты B₀, …, Bₙ₋₁ читаются старшим вперёд. Число накапливается так:

m = 0
Для каждого байта Bᵢ от начала блока к концу:
    m = 256·m + Bᵢ

Умножение на 256 сдвигает уже прочитанные байты на один байт влево, а прибавление Bᵢ занимает освободившийся младший байт. Длина n хранится отдельно от значения m: ведущие нулевые байты сами по себе не меняют число.

Почему нельзя просто взять x = m

Не для каждого x существует y, удовлетворяющий уравнению кривой. Поэтому к числу m приписывается один служебный байт t. Он позволяет менять x, сохраняя исходное m:

x = 256m + t, где t = 0, 1, …, 255

Для каждого t вычисляются правая часть уравнения u и кандидат на координату y:

u = (x³ + a·x + b) mod p
y = u^((p + 1)/4) mod p

Если y² mod p = u:
    точка M = (x, y) найдена
Иначе:
    попробовать следующее t

Перебор начинается с t = 0. Для каждого t заново вычисляются x и u; первая успешная проверка завершает кодирование. t нужен только для поиска допустимой точки и не является секретом или случайным параметром шифрования. Одноразовый секрет k выбирается позже, независимо от t.

Формула для y применима, потому что выбранный модуль удовлетворяет p mod 4 = 3. Проверка y² обязательна: при отсутствии квадратного корня кандидат не подходит. Если все 256 значений t исчерпаны, кодирование завершается ошибкой.

Если у ненулевого u есть квадратный корень, обычно существуют два значения y: y и −y mod p. Для кодирования достаточно любого одного из них: в обоих случаях x одинаков и из него извлекается одно и то же m. Программа использует значение, полученное указанным возведением в степень.

30 байтов занимают 240 бит. С добавленным байтом t получается не более 248 бит, поэтому x заведомо меньше выбранного 256-битного p.

Как вернуть исходный блок

После расшифрования берётся x-координата точки M и отбрасывается её младший байт:

m = ⌊x(M)/256⌋

Знак ⌊ ⌋ означает целую часть. Число m снова записывается в байты старшим вперёд. Длина исходного блока известна: она нужна, чтобы сохранить ведущие нули и правильно восстановить короткий последний блок.

Кодирование не использует M = mP: такое преобразование потребовало бы при декодировании искать m по точке, то есть решать задачу дискретного логарифмирования. Здесь m непосредственно включено в x, поэтому после восстановления M извлекается обычным целочисленным делением.

4. Как выполняется шифрование

У отправителя есть открытый ключ Q и точка сообщения M. Он выбирает случайное число k в диапазоне 1 ≤ k < q. Это временный секрет только для текущего блока; постоянный ключ d при этом не меняется.

C₁ = kP
S  = kQ
C₂ = M + S

Умножения kP и kQ выполняются над точками по одному и тому же k. Результат каждого — точка с двумя координатами. Затем M и S складываются по формулам кривой; побайтовое сложение или XOR сообщения здесь не используется.

S — маскирующая точка. Она прибавляется к M и скрывает её. Получившаяся C₂ сама по себе не сообщает получателю, какую точку надо вычесть. Для этого вместе с ней передаётся C₁.

Часть шифротекстаДля чего нужна
C₁ = kPПозволяет получателю с помощью d вычислить маскирующую точку S. Число k из неё напрямую не извлекается.
C₂ = M + kQСодержит точку сообщения с добавленной маскирующей точкой.

Получателю передаётся пара точек (C₁, C₂). Числа d и k и сама точка S в неё не входят. Наблюдатель знает P, Q = dP и C₁ = kP. Ему требуется получить kdP, не зная ни d, ни k. Это вычислительная задача Диффи — Хеллмана на эллиптической кривой. Умножить координаты Q и C₁ друг на друга нельзя: такая операция не даёт kdP.

Для каждого блока выбирается новое случайное k. Поэтому одинаковые блоки обычно дают разные шифротексты. Если повторить k, добавка S тоже повторится, и разность вторых точек раскроет разность точек сообщений: C₂₁ − C₂₂ = M₁ − M₂.

C₁ всегда принадлежит подгруппе P и не равна O, поскольку 1 ≤ k < q. Точка S тоже принадлежит этой подгруппе. Точка C₂ может находиться вне неё, потому что M получена кодированием координаты, а не умножением P.

В этой реализации хранятся только конечные точки. Если C₂ = O, выбирается новое k и вычисления повторяются. После обработки всех блоков получается последовательность пар точек.

5. Как выполняется расшифрование

У получателя есть закрытый ключ d и полученная пара (C₁, C₂). До вычислений проверяются:

  • 1 ≤ d < q — допустимый диапазон закрытого ключа.
  • C₁ ≠ O и C₂ ≠ O — формат данной реализации допускает только конечные точки.
  • У каждой точки координаты находятся в диапазоне 0…p−1 и удовлетворяют уравнению кривой.
  • qC₁ = O — первая точка должна быть кратной P. Для C₂ это условие не требуется, поскольку M может находиться вне подгруппы P.

Затем выполняются два действия:

S′ = dC₁       — вычислить маскирующую точку
M  = C₂ − S′   — убрать её из сообщения

Почему получается та же добавка

Отправитель использовал открытый ключ Q = dP, а первая точка шифротекста равна C₁ = kP. Подставим их в формулы:

У отправителя: S = kQ = k(dP)
У получателя: S′ = dC₁ = d(kP)
k(dP) = d(kP), поэтому S′ = S

Оба получили одну и ту же точку разными способами. Отправитель знает k и использует Q, получатель знает d и использует C₁. Получателю не требуется восстанавливать k.

C₂ − S′ = (M + S) − S = M

Вычитание означает прибавление противоположной точки: если S′ = (x, y), то −S′ = (x, −y mod p). Поэтому добавленные при шифровании точки взаимно уничтожаются.

Восстановление байтов

Если восстановленная M равна O, декодирование отклоняется. В программе вычисления точек идут в якобиановых координатах (X, Y, Z), поэтому сначала получают обычную x-координату: x = X·(Z⁻¹)² mod p. Только после этого вычисляют m = ⌊x/256⌋. Делить внутреннюю координату X на 256 нельзя.

Проверяется диапазон 0 ≤ m < 2²⁴⁰. Число записывается в 30-байтовое поле старшим байтом вперёд с ведущими нулями. Из поля берутся последние n байтов. Полные блоки имеют n = 30; длина последнего определяется по общей исходной длине сообщения, сохранённой при шифровании. Это позволяет восстановить короткий остаток и не потерять нулевые байты.

Блоки объединяются в прежнем порядке. Для пустого сообщения блоки не создаются, и результат расшифрования тоже пустой.

Обычный Эль-Гамаль не содержит проверки подлинности. Проверки ключей и точек отсекают недопустимые данные, но не гарантируют обнаружение любого изменения шифротекста. Например, прибавление точки T к C₂ изменяет результат расшифрования с M на M + T.
