Лабораторная работа № 7

Эль-Гамаль на эллиптической кривой

Блок сообщения превращается в точку M. Отправитель скрывает её с помощью открытого ключа Q, получая две точки C₁ и C₂. Получатель восстанавливает M закрытым ключом d и извлекает исходные байты.

1. Параметры и операции над точками

В программе заранее заданы параметры кривой id-tc26-gost-3410-2012-256-paramSetA. Это выбор кривой для реализации Эль-Гамаля; сам алгоритм здесь шифрует данные.

E: y² ≡ x³ + a·x + b (mod p)
ОбозначениеЗначение
pПростой модуль координат. Все координаты и формулы сложения считаются по модулю p.
a, bКоэффициенты уравнения кривой.
PБазовая точка с заданными координатами. Заглавная P — точка, строчная p — число.
qПростой порядок P: qP = O. Секретные множители выбираются в диапазоне 1…q−1. Порядок всей группы этой кривой равен 4q.
OТочка на бесконечности — нейтральный элемент: A + O = A.
M, C₁, C₂, QТочки с двумя координатами. Буква M обозначает точку сообщения, B — исходный блок байтов, m — целое число из B.

mod означает остаток от деления. Запись kP означает сложение точки P с собой k раз по правилам кривой. Координаты точки на k не умножаются. В программе используются удвоения и сложения по битам k.

Сложение, удвоение и вычитание

Для разных точек A = (x₁, y₁), B = (x₂, y₂) с x₁ ≠ x₂:

λ = (y₂ − y₁) · (x₂ − x₁)⁻¹ mod p
x₃ = λ² − x₁ − x₂ mod p
y₃ = λ · (x₁ − x₃) − y₁ mod p
A + B = (x₃, y₃)

При удвоении A = B используется λ = (3x₁² + a) · (2y₁)⁻¹ mod p. Если точки противоположны, сумма равна O; при удвоении точки с y = 0 результат тоже O.

−A = (x₁, −y₁ mod p)
A − B = A + (−B)

Обратное число t⁻¹ удовлетворяет t·t⁻¹ mod p = 1. В коде точки хранятся в якобиановых координатах (X, Y, Z), чтобы не вычислять обратное при каждом сложении. Обычные координаты: x = X/Z², y = Y/Z³ по модулю p.

2. Как связаны открытый и закрытый ключи

Выбрать случайное целое d: 1 ≤ d < q
Вычислить Q = dP

Закрытый ключ — число d, открытый ключ — точка Q. Пара создаётся один раз и может применяться к разным сообщениям. Отправителю нужен Q; получателю для расшифрования нужен d.

Открытый ключ должен быть конечной точкой на кривой и удовлетворять qQ = O. Сначала проверяются диапазон координат и уравнение кривой, затем порядок. Точка O в формате открытого ключа не допускается.

Числа d и одноразовые k получаются из 32 случайных байтов системного генератора Windows BCryptGenRandom. Ноль и числа не меньше q отбрасываются; генерация повторяется.

3. Как байты превращаются в точку

Эль-Гамаль в этой реализации работает с точками. Поэтому файл делится на блоки B длиной не более 30 байтов. Длина текущего блока n сохраняется через общую длину файла; последний блок может быть короче.

  1. Прочитать B как целое число m старшим байтом вперёд: например, байты 01 02 дают m = 258.
  2. Задать t = 0 и вычислить x = 256m + t. Младший байт x выделен под t.
  3. Вычислить u = (x³ + ax + b) mod p.
  4. Найти кандидата y = u^((p+1)/4) mod p. Такая формула применима, поскольку у выбранного p остаток от деления на 4 равен 3.
  5. Если y² mod p = u, получить M = (x, y). Иначе увеличить t на 1 и повторить с шага 2. Проверяются t от 0 до 255.

Для 30 байтов m < 2²⁴⁰, поэтому x < 2²⁴⁸ < p. Если все 256 вариантов t исчерпаны, кодирование возвращает ошибку. В схеме ниже блок «Закодировать B в точку M» означает именно этот перебор.

Обратное преобразование

m = ⌊x(M)/256⌋

Деление отбрасывает байт t. Число m записывается старшим байтом вперёд в поле из 30 байтов с ведущими нулями. Для блока длиной n берутся последние n байтов. Благодаря известной длине восстанавливаются и исходные ведущие нули.

Это обратимое кодирование, которое сохраняет сообщение. Хэширование здесь не выполняется.

4. Шифрование одного блока

Шифрование скрывает точку сообщения M за случайной добавкой S. Открытый ключ Q позволяет отправителю вычислить эту добавку, не зная d.

Выбрать новое случайное k: 1 ≤ k < q
C₁ = kP
S  = kQ
C₂ = M + S
Шифротекст блока: (C₁, C₂)

Для каждого блока выбирается новое k. Повторное шифрование одинаковых байтов обычно даёт другую пару точек. k и S не записываются в файл.

При редком совпадении M = −S вторая точка становится O. Контейнер хранит только конечные точки, поэтому программа выбирает новое k и повторяет вычисления C₁, S, C₂. C₁ всегда конечна, поскольку 1 ≤ k < q и порядок P равен q.

Получателю передаётся пара C₁, C₂. Полное сообщение обрабатывается повторением этого алгоритма для каждого непустого блока.

5. Расшифрование и причина его корректности

Получатель проверяет диапазон d, принадлежность C₁ и C₂ кривой и условие qC₁ = O. Затем закрытым ключом восстанавливает ту же добавку, которую использовал отправитель:

S' = dC₁
M  = C₂ − S'
m  = ⌊x(M)/256⌋
Восстановить n исходных байтов из m

Сначала M должна оказаться конечной точкой, затем m должно помещаться в 240 бит. Иначе декодирование отклоняется. Для C₂ условие qC₂ = O не требуется: точка M при кодировании может принадлежать всей группе кривой, а не подгруппе P.

Почему добавка сокращается

Q = dP, C₁ = kP
S' = dC₁ = d(kP) = k(dP) = kQ = S
C₂ − S' = (M + S) − S = M

Отправитель получил S через k и Q, получатель — через d и C₁. Оба пришли к одной точке, поэтому вычитание возвращает M без поиска k.

Эта схема обеспечивает шифрование без встроенной проверки подлинности. Проверки точек и структуры файла отсекают недопустимые данные, но не гарантируют обнаружение любого изменения шифротекста или любого неверного ключа. Эль-Гамаль допускает изменение C₂ добавлением другой точки; подпись или код аутентификации в этой лабораторной не реализованы.

6. Описание блок-схем алгоритма

Слева — шифрование, справа — расшифрование одного блока B длиной n, 1 ≤ n ≤ 30. Параметры E, p, q, P заданы заранее, Q = dP. Разбор аргументов, команды, файловые заголовки и сообщения интерфейса в схемы не входят. Для файла алгоритм повторяется по блокам; пустой файл не содержит точек шифротекста.

Шифрование — слева

Назначение схемы — преобразовать исходный блок в пару точек с помощью открытого ключа. Случайное k создаёт новую маскирующую добавку для каждого блока.

Что сохраняется в шифротексте

Заголовок занимает 20 байтов: сигнатура ECELG1\0\0 (8), версия 1 (1), размер блока 30 (1), два нулевых резервных байта (2), исходная длина файла в little-endian (8). Затем идут пары C₁, C₂ по 128 байтов: x₁, y₁, x₂, y₂ — каждое число по 32 байта в big-endian.

Размер шифротекста = 20 + 128 · ⌈длина файла / 30⌉ байтов

Пустой файл даёт только заголовок. Для последнего блока n определяется по исходной длине, поэтому нули не теряются. При чтении проверяются заголовок, точный размер контейнера, точки и ключ; выходной файл расшифрования открывается после успешной обработки всех блоков.

Сборка и команды проверки приведены в TEST.md. При сравнении исходного и восстановленного файлов ожидается FC: no differences encountered. При сравнении двух шифротекстов одного сообщения ожидаются различия из-за новых k.
