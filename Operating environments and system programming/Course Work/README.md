## File Manager – интерактивный консольный файловый менеджер

### Описание
Программа представляет собой интерактивное консольное приложение для просмотра и управления файловой системой.  
**Основные возможности:**
- Отображение дерева каталогов (иерархическая структура с возможностью раскрытия/сворачивания)
- Плоский список текущего каталога (альтернативный режим)
- Навигация с помощью стрелок, Enter, Backspace
- Операции: копирование, перемещение, удаление, создание файлов и каталогов через системные вызовы
- Поддержка UTF-8 (русские, китайские и другие символы)
- Корректная обработка ошибок (нет прав, файл занят, не найдено) с выводом сообщений на английском
- Логирование всех операций и ошибок в файл `file_manager.log`
- Изменение размера окна обрабатывается без потери данных

### Требования
- Операционная система Linux (Ubuntu)
- Библиотека ncursesw: `sudo apt install libncursesw5-dev`
- Компилятор с поддержкой C++17

### Сборка
```bash
make
```

### Запуск
```bash
./file_manager [начальный_путь]
```
Если путь не указан, используется текущий каталог.

### Управление
| Клавиша | Действие |
|---------|----------|
| ↑ / ↓ | Перемещение по списку |
| Enter | В режиме дерева: раскрыть/свернуть каталог. В плоском режиме: войти в выбранный каталог |
| Backspace | Перейти в родительский каталог (работает в обоих режимах) |
| t | Переключить режим отображения (дерево ↔ плоский список) |
| c | Копировать выбранный элемент. Предлагается путь назначения (по умолчанию – родительский каталог выбранного элемента) |
| m | Переместить/переименовать выбранный элемент. Предлагается текущее имя |
| d | Удалить выбранный элемент (требуется подтверждение) |
| n | Создать новый файл (f) или каталог (d). Элемент создаётся в текущем выбранном каталоге (или родительском для файла) |
| q | Выход из программы |

**Команды не чувствительны к регистру** (работают как с включённым Caps Lock, так и в нижнем регистре).  
Все сообщения выводятся на английском языке в статусной строке внизу экрана.

### Пример использования
1. Запустить программу: `./file_manager /home/user`
2. Перейти в режим дерева (по умолчанию) или нажать `t` для плоского списка.
3. Выбрать каталог стрелками и нажать `Enter`, чтобы раскрыть его.
4. Для копирования файла нажать `c`, отредактировать предлагаемый путь (можно стрелками, Backspace) и нажать `Enter`.
5. Для удаления – нажать `d`, подтвердить `y`.
6. Выход – `q`.

### Тестирование

#### 1. Тест на корректность завершения
```bash
# Очистка и сборка
make clean && make

# Запуск программы в тестовом каталоге
./file_manager /tmp

# Выполнить последовательность действий:
# - Нажать Enter для входа в подкаталог (если есть)
# - Нажать t для переключения режима
# - Нажать c для копирования выбранного файла/папки (отменить Ctrl+C)
# - Нажать q для выхода

# Проверить код возврата
echo $?   # Должно быть 0
```
Ожидаемый результат: программа завершается без ошибок, код возврата 0. Лог-файл `file_manager.log` содержит записи о выполненных операциях (если они были).

#### 2. Тест на производительность
```bash
# Создать тестовую структуру (1000 файлов по 10 МБ)
mkdir -p /tmp/perf
for i in {1..1000}; do dd if=/dev/zero of=/tmp/perf/file$i bs=1M count=10 2>/dev/null; done

# Запустить программу с замером времени
time ./file_manager /tmp/perf

# В программе:
# - Выбрать любой файл (например, первый)
# - Нажать c, ввести новый путь (например, /tmp/perf_copy), нажать Enter
# - Дождаться завершения копирования
# - Выбрать скопированный файл, нажать d, подтвердить y
# - Нажать q
```
Ожидаемое время: копирование одного файла 10 МБ занимает доли секунды. При копировании большого числа файлов производительность ограничена скоростью диска. Программа не зависает, навигация остаётся отзывчивой.  
При возникновении ошибок (например, нет прав) выводятся сообщения и запись в лог.

### Логирование
Все операции и ошибки записываются в файл `file_manager.log` в текущем каталоге. Пример записи:
```
Copied file: /tmp/perf/file1 -> /tmp/perf_copy/file1
Moved /tmp/perf_copy/file1 -> /tmp/perf/file1_backup
Deleted /tmp/perf/file1_backup
Error: cannot open directory /root/.ssh - Permission denied
```
Лог открывается в режиме добавления (append), поэтому старые записи не удаляются.

### Примечания по реализации
- Для копирования и удаления каталогов используется рекурсивный обход.
- Права доступа к создаваемым файлам: 0644, к каталогам: 0755.
- При отсутствии прав доступа операция прерывается с выводом соответствующего сообщения.
- При изменении размера окна интерфейс автоматически перестраивается.
