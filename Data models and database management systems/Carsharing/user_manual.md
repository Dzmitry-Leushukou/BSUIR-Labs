# Руководство пользователя для приложения каршеринга

## Общие сведения

Приложение каршеринга позволяет пользователям арендовать автомобили на короткие промежутки времени. Система включает в себя интерфейс для обычных пользователей и административную панель для управления системой.

## Основные функции

### 1. Авторизация и регистрация

#### Регистрация нового пользователя
1. Нажмите кнопку "Регистрация" в правом верхнем углу главной страницы
2. Введите свою электронную почту, имя, фамилию и пароль
3. После успешной регистрации вы автоматически войдете в систему

#### Вход в систему
1. Нажмите кнопку "Войти" в правом верхнем углу главной страницы
2. Введите свою электронную почту и пароль
3. Нажмите "Войти" для входа в систему

#### Выход из системы
1. Нажмите на область профиля в правом верхнем углу
2. Нажмите кнопку "Выйти"

### 2. Просмотр и аренда автомобилей

#### Просмотр доступных автомобилей
1. После входа в систему вы увидите карту с маркерами автомобилей
2. Зеленые маркеры означают доступные для аренды автомобили
3. Красные маркеры означают автомобили, недоступные для аренды
4. Оранжевые маркеры означают автомобили, которые арендованы вами

#### Аренда автомобиля
1. Нажмите на маркер доступного автомобиля на карте
2. В появившемся окне нажмите кнопку "Арендовать"
3. После аренды автомобиль будет отмечен оранжевым маркером
4. Панель активной аренды появится в нижней части экрана

### 3. Управление арендой

#### Просмотр активной аренды
1. Панель активной аренды отображает информацию о текущей аренде
2. Панель показывает модель автомобиля, номер, статус и текущую цену

#### Завершение аренды
1. Нажмите кнопку "Завершить" на панели активной аренды
2. Откроется модальное окно завершения аренды
3. Добавьте фотографии автомобиля (минимум одна обязательна)
4. Введите данные банковской карты для оплаты
5. При необходимости используйте кэшбэк для оплаты
6. Нажмите "Оплатить и завершить" для завершения аренды

### 4. Личный профиль

#### Доступ к профилю
1. Нажмите на область профиля в правом верхнем углу
2. Откроется страница вашего профиля

#### Редактирование профиля
1. На странице профиля нажмите кнопку "Редактировать профиль"
2. Введите новые данные в соответствующие поля
3. Нажмите "Сохранить" для сохранения изменений

#### Смена пароля
1. На странице профиля нажмите кнопку "Сменить пароль"
2. Введите текущий пароль, новый пароль и подтверждение нового пароля
3. Нажмите "Сменить пароль" для сохранения изменений

#### Загрузка водительских прав
1. На странице профиля нажмите кнопку "Загрузить водительские права"
2. Введите номер прав, кем выданы и дату окончания
3. Загрузите фотографии обеих сторон водительского удостоверения
4. Нажмите "Загрузить" для отправки на проверку

#### Просмотр истории аренды
1. На странице профиля нажмите кнопку "Мои заказы"
2. Откроется таблица с историей всех ваших аренд

### 5. Кэшбэк

#### Просмотр кэшбэка
1. Кэшбэк отображается на главной странице и в профиле
2. Кэшбэк начисляется в белорусских рублях (BYN)

#### Использование кэшбэка
1. При завершении аренды в модальном окне появляется возможность использовать кэшбэк
2. Поставьте галочку "Использовать кэшбэк" для применения
3. При необходимости укажите сумму кэшбэка для использования

## Административная панель

Административная панель доступна только пользователям с ролью администратора.

### 1. Доступ к административной панели
1. Убедитесь, что вы вошли как администратор
2. Нажмите кнопку "Админ панель" в правом верхнем углу главной страницы

### 2. Управление таблицами
Административная панель включает следующие таблицы:
- Пользователи
- Автомобили
- Аренды
- Логи действий
- Подтверждение документов
- Запросы на обслуживание
- Логи платежей
- Подтверждение завершения поездок

### 3. Таблица пользователей
1. Просмотр информации о пользователях
2. Изменение роли пользователя (администратор, пользователь, менеджер)
3. Блокировка/разблокировка пользователей
4. Удаление пользователей

### 4. Таблица автомобилей
1. Просмотр информации об автомобилях
2. Добавление новых автомобилей
3. Редактирование информации об автомобиле
4. Фильтрация по различным параметрам

### 5. Таблица подтверждения документов
1. Просмотр загруженных водительских прав пользователей
2. Подтверждение или отклонение документов
3. Просмотр фотографий водительских прав

### 6. Таблица подтверждения завершения поездок
1. Просмотр запросов на подтверждение завершения поездок
2. Подтверждение завершения поездки без повреждений
3. Отметка о наличии повреждений с созданием запроса на обслуживание
4. Просмотр фотографий автомобиля после поездки

## Безопасность и конфиденциальность

1. Не делитесь своими учетными данными с другими пользователями
2. Используйте надежные пароли
3. Всегда выходите из системы при использовании общедоступных компьютеров
4. Сообщайте о любых подозрительных действиях в службу поддержки

## Техническая поддержка

Если у вас возникли проблемы с использованием приложения:
1. Проверьте подключение к интернету
2. Обновите страницу
3. Очистите кэш браузера
