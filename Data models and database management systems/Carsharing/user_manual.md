# Руководство пользователя для приложения каршеринга

## Глава 1: Руководство для пользователя

### 1.1 Общие сведения

Приложение каршеринга позволяет пользователям арендовать автомобили на определенные промежутки времени. Сервис включает в себя систему бронирования, отслеживания поездок, оплаты и управления личным кабинетом.

### 1.2 Регистрация и авторизация

#### 1.2.1 Регистрация нового пользователя
1. Нажмите кнопку "Регистрация" в правом верхнем углу главной страницы
2. Введите свою электронную почту, имя, фамилию и пароль
3. После успешной регистрации вы автоматически войдете в систему
4. Для использования сервиса необходимо загрузить и подтвердить водительские права

#### 1.2.2 Вход в систему
1. Нажмите кнопку "Войти" в правом верхнем углу главной страницы
2. Введите свою электронную почту и пароль
3. Нажмите "Войти" для входа в систему
4. В случае неправильных данных система сообщит об ошибке, и вы сможете повторить попытку

#### 1.2.3 Выход из системы
1. Нажмите кнопку "Выйти" в правом верхнем углу
2. После выхода все сессии будут завершены, и вам потребуется снова войти в систему для использования приложения

### 1.3 Просмотр и аренда автомобилей

#### 1.3.1 Просмотр доступных автомобилей
1. После входа в систему вы увидите карту с маркерами автомобилей
2. Зеленые маркеры означают доступные для аренды автомобили
3. Оранжевые маркеры означают автомобили, которые арендованы вами
4. Красные маркеры означают автомобили, которые недоступны (на обслуживании)
5. Для получения информации о конкретном автомобиле нажмите на его маркер на карте
6. В появившемся окне вы увидите модель автомобиля, его номер и дополнительную информацию

#### 1.3.2 Аренда автомобиля
1. Нажмите на маркер доступного автомобиля на карте
2. В появившемся окне нажмите кнопку "Арендовать"
3. После аренды автомобиль будет отмечен оранжевым маркером
4. Панель активной аренды появится в нижней части экрана
5. В панели активной аренды вы можете отслеживать стоимость поездки в реальном времени
6. Аренда начинается с фиксированной ставки 1 BYN плюс 0.5 BYN за каждую минуту использования

### 1.4 Управление арендой

#### 1.4.1 Просмотр активной аренды
1. Панель активной аренды отображает информацию о текущей аренде в нижней части экрана
2. Панель показывает модель автомобиля, номер, статус и текущую цену
3. Цена обновляется в реальном времени каждую секунду
4. В панели также отображается время начала аренды

#### 1.4.2 Завершение аренды
1. Нажмите кнопку "Завершить" на панели активной аренды
2. Откроется модальное окно завершения аренды
3. Добавьте фотографии автомобиля (минимум одна обязательна)
4. Введите данные банковской карты для оплаты
5. При необходимости используйте кэшбэк для оплаты
6. Нажмите "Оплатить и завершить" для завершения аренды
7. После завершения аренды статус изменится на "Ожидает подтверждения", и администратор должен будет подтвердить завершение поездки
8. После подтверждения администратором поездка считается завершенной

### 1.5 Личный профиль

#### 1.5.1 Доступ к профилю
1. Нажмите на область профиля в правом верхнем углу (имя и фамилия пользователя)
2. Откроется страница вашего профиля
3. На странице профиля вы можете редактировать свои данные, просматривать историю поездок и управлять настройками

#### 1.5.2 Редактирование профиля
1. На странице профиля нажмите кнопку "Редактировать профиль"
2. Введите новые данные в соответствующие поля (имя, фамилия, email)
3. Нажмите "Сохранить" для сохранения изменений
4. Изменения вступят в силу немедленно

#### 1.5.3 Смена пароля
1. На странице профиля нажмите кнопку "Сменить пароль"
2. Введите текущий пароль, новый пароль и подтверждение нового пароля
3. Нажмите "Сменить пароль" для сохранения изменений
4. После смены пароля вы будете автоматически выведены из системы и должны будете снова войти

#### 1.5.4 Загрузка водительских прав
1. На странице профиля нажмите кнопку "Загрузить водительские права"
2. Введите номер прав, кем выданы и дату окончания
3. Загрузите фотографии обеих сторон водительского удостоверения
4. Нажмите "Загрузить" для отправки на проверку
5. Статус проверки будет обновлен в течение 24 часов
6. После подтверждения вы сможете использовать сервис каршеринга
7. Статусы водительских прав: "Не отправлены на проверку", "Ожидает проверки", "Подтверждено", "Отклонено"

#### 1.5.5 Просмотр истории аренды
1. На странице профиля нажмите кнопку "Мои заказы"
2. Откроется таблица с историей всех ваших аренд
3. В таблице отображаются даты начала и окончания, стоимость поездки, статус и информация о транспортном средстве
4. Для получения детальной информации о конкретной поездке нажмите на соответствующую строку
5. Используется пагинация для навигации по заказам

### 1.6 Кэшбэк

#### 1.6.1 Просмотр кэшбэка
1. Кэшбэк отображается на главной странице и в профиле
2. Кэшбэк начисляется в белорусских рублях (BYN)
3. Кэшбэк накапливается автоматически после каждой завершенной поездки
4. Отображается текущий баланс и общая сумма накопленного кэшбэка

#### 1.6.2 Использование кэшбэка
1. При завершении аренды в модальном окне появляется возможность использовать кэшбэк
2. Поставьте галочку "Использовать кэшбэк" для применения
3. При необходимости укажите сумму кэшбэка для использования (если не указать, будет использовано максимально возможное количество)
4. Кэшбэк автоматически применяется к общей сумме поездки
5. За каждую поездку начисляется 3% от стоимости в виде кэшбэка

### 1.7 Безопасность и конфиденциальность

#### 1.7.1 Рекомендации по безопасности
1. Не делитесь своими учетными данными с другими пользователями
2. Используйте надежные пароли (не менее 8 символов, включая буквы, цифры и специальные символы)
3. Всегда выходите из системы при использовании общедоступных компьютеров
4. Проверяйте автомобиль перед поездкой и делайте фотографии для безопасности
5. Убедитесь, что водительские права действительны и не просрочены

#### 1.7.2 Защита персональных данных
1. Данные используются только для предоставления услуг каршеринга
2. Мы не передаем ваши данные третьим лицам без вашего согласия
3. Данные хранятся в зашифрованном виде

## Глава 2: Руководство для администратора

### 2.1 Общие сведения

Административная панель предназначена для управления системой каршеринга. Администраторы имеют доступ ко всем аспектам системы, включая управление пользователями, автомобилями, арендами, документами и логами действий. Доступ к административной панели имеют только пользователи с ролью администратора (ID роли = 1).

### 2.2 Доступ к административной панели

#### 2.2.1 Вход в административную панель
1. Убедитесь, что вы вошли в систему как пользователь с ролью администратора
2. Нажмите кнопку "Админ панель" в правом верхнем углу главной страницы
3. После нажатия вы попадете на главную страницу административной панели

#### 2.2.2 Структура административной панели
1. Главная страница административной панели содержит сетку с кнопками для доступа к различным таблицам
2. Все таблицы имеют единый интерфейс с возможностью фильтрации, постраничной навигации и действий
3. В верхней части каждой страницы есть кнопка "Назад" для возврата в административную панель
4. Все изменения, внесенные в систему, автоматически регистрируются в логах действий

### 2.3 Управление таблицами

Административная панель включает следующие таблицы:

#### 2.3.1 Таблицы в административной панели:
- Пользователи
- Автомобили
- Аренды
- Логи действий
- Подтверждение документов
- Запросы на обслуживание
- Логи платежей
- Подтверждение завершения поездок

### 2.4 Таблица пользователей

#### 2.4.1 Просмотр информации о пользователях
1. На странице таблицы пользователей отображаются все зарегистрированные пользователи
2. Колонки таблицы включают: ID, Email, Имя, Фамилия, Кэшбэк, ID роли, Статус, Дата создания, Дата обновления
3. Используйте фильтры для поиска конкретных пользователей по различным критериям
4. Для навигации по большим объемам данных используйте постраничную навигацию внизу таблицы

#### 2.4.2 Изменение роли пользователя
1. Найдите нужного пользователя в таблице
2. Нажмите кнопку "Изменить роль" в строке пользователя
3. Введите ID новой роли (1 - администратор, 2 - пользователь)
4. Подтвердите изменение
5. Изменение роли будет зарегистрировано в логах действий
6. Внимание: предоставление роли администратора дает пользователю доступ ко всей административной панели

#### 2.4.3 Блокировка/разблокировка пользователей
1. Найдите нужного пользователя в таблице
2. Нажмите кнопку "Заблокировать" или "Разблокировать" в зависимости от текущего статуса
3. Подтвердите действие в появившемся диалоговом окне
4. Заблокированный пользователь не сможет войти в систему и использовать сервис
5. Статусы пользователей: "Активен", "Заблокирован"
6. Все действия по блокировке/разблокировке регистрируются в логах

### 2.5 Таблица автомобилей

#### 2.5.1 Просмотр информации об автомобилях
1. Таблица автомобилей отображает все автомобили в системе
2. Колонки включают: ID, VIN, Номерной знак, Модель, Статус, Позиция, Дата обновления
3. Статусы автомобилей: "Доступен", "Арендован", "На обслуживании", "Ожидает завершения"
4. Используйте фильтры для поиска автомобилей по различным параметрам

#### 2.5.2 Добавление новых автомобилей
1. Нажмите кнопку "Добавить автомобиль" верхней части страницы
2. Заполните все поля формы: VIN, Номерной знак, Модель
3. Выберите статус автомобиля (по умолчанию "Доступен")
4. При необходимости укажите позицию в формате "широта, долгота" (например: 53.9041, 27.5615)
5. Нажмите "Сохранить" для добавления автомобиля в систему

#### 2.5.3 Редактирование информации об автомобиле
1. Найдите нужный автомобиль в таблице
2. Нажмите кнопку "Редактировать" в строке автомобиля
3. Внесите необходимые изменения в поля формы
4. Нажмите "Сохранить" для обновления информации
5. Изменения вступают в силу немедленно и отражаются в системе

#### 2.5.4 Изменение статуса автомобиля
1. Автомобиль может иметь один из следующих статусов:
   - "Доступен" - автомобиль доступен для аренды
   - "Арендован" - автомобиль в настоящее время арендован
   - "На обслуживании" - автомобиль недоступен из-за технических работ
   - "Ожидает завершения" - автомобиль участвует в завершающейся поездке
2. Изменяйте статус только при необходимости и с пониманием последствий
3. Изменение статуса может повлиять на активные аренды и доступность для пользователей

### 2.6 Таблица подтверждения документов

#### 2.6.1 Просмотр загруженных водительских прав
1. Таблица отображает все загруженные водительские права пользователей
2. Колонки включают: ID пользователя, Номер прав, Кем выданы, Дата окончания, Фото (лицевая и обратная стороны), Статус
3. Статусы документов: "Ожидает проверки", "Подтверждено", "Отклонено"
4. Для просмотра фотографий документов нажмите на изображение для увеличения
5. Доступна пагинация для навигации по документам

#### 2.6.2 Подтверждение документов
1. Найдите документ со статусом "Ожидает проверки"
2. Проверьте качество фотографий и достоверность информации
3. Убедитесь, что документ действителен (не просрочен)
4. Нажмите кнопку "Подтвердить" для одобрения документа
5. После подтверждения пользователь получит доступ к услугам каршеринга
6. Все действия по подтверждению документов регистрируются в логах

#### 2.6.3 Отклонение документов
1. Найдите документ, который нужно отклонить
2. Убедитесь, что есть основания для отклонения (просрочен, плохое качество фото, подозрительная информация)
3. Нажмите кнопку "Отклонить" в строке документа
4. Пользователь будет уведомлен об отклонении и сможет загрузить новые документы
5. Рекомендуется связаться с пользователем для объяснения причины отклонения

### 2.7 Таблица подтверждения завершения поездок

#### 2.7.1 Просмотр запросов на подтверждение завершения поездок
1. Таблица отображает все поездки, ожидающие подтверждения завершения
2. Колонки включают: ID пользователя (Email), VIN автомобиля, Время начала и окончания, Цена, Фото, Статус
3. Статусы: "На рассмотрении" (ожидает подтверждения администратором), "Подтверждено" (аренда завершена без повреждений), "Обнаружены повреждения" (аренда завершена с повреждениями)
4. Используйте фильтры для поиска поездок по различным критериям
5. Доступна пагинация для навигации по поездкам

#### 2.7.2 Подтверждение завершения поездки без повреждений
1. Найдите поездку со статусом "На рассмотрении"
2. Просмотрите загруженные пользователем фотографии автомобиля
3. Убедитесь, что нет видимых повреждений транспортного средства
4. Нажмите кнопку "Повреждений нет" для подтверждения завершения поездки
5. После подтверждения статус поездки изменится на "Подтверждено"
6. Состояние автомобиля обновится, и он станет доступен для следующей аренды

#### 2.7.3 Отметка о наличии повреждений
1. Найдите поездку с признаками повреждений автомобиля
2. Нажмите кнопку "Обнаружены повреждения"
3. Введите описание повреждений в появившемся диалоговом окне
4. Система автоматически создаст запрос на обслуживание для автомобиля
5. Автомобиль будет переведен в статус "На обслуживании" до устранения повреждений
6. Пользователю может быть начислен штраф в зависимости от серьезности повреждений

#### 2.7.4 Просмотр фотографий автомобиля после поездки
1. В таблице завершения поездок нажмите на ячейку с фотографией
2. Фотографии увеличатся в модальном окне для детального рассмотрения
3. Просмотрите все загруженные фотографии для оценки состояния автомобиля
4. Сравните с фотографиями до поездки при наличии (если были сделаны)
5. Увеличенные фотографии можно листать, если загружено несколько изображений

### 2.8 Таблица аренд

#### 2.8.1 Просмотр всех аренд
1. Таблица аренд отображает все аренды в системе
2. Колонки включают: ID, ID пользователя, ID автомобиля, Время начала и окончания, Цена, Статус
3. Статусы аренд: "Активна", "Завершена", "Отменена", "Ожидает завершения"
4. Используйте фильтры для поиска аренд по пользователям, автомобилям или датам
5. Доступна пагинация для навигации по арендам

#### 2.8.2 Мониторинг активных аренд
1. Активные аренды имеют статус "Активна"
2. Для каждой активной аренды отображается текущая стоимость и продолжительность

### 2.9 Таблица логов действий

#### 2.9.1 Просмотр логов действий
1. Таблица логов содержит все важные действия в системе
2. Колонки включают: ID, ID пользователя-инициатора, Тип действия, Целевые ID, Описание, Старые/новые значения, Дата создания
3. Используйте фильтры для поиска конкретных типов действий или действий конкретных пользователей
4. Логи помогают отслеживать изменения в системе и выявлять подозрительную активность
5. Доступна пагинация для навигации по логам

#### 2.9.2 Интерпретация типов действий
1. Система использует следующие типы действий:
   - "Вход пользователя", "Выход пользователя", "Регистрация пользователя"
   - "Начало аренды автомобиля", "Завершение аренды автомобиля", "Отмена аренды автомобиля", "Ожидание завершения аренды"
   - "Успешный платеж", "Неудачный платеж"
   - "Запрос на обслуживание", "Решение запроса на обслуживание"
   - "Обновление профиля", "Загрузка водительских прав"
   - "Изменение статуса автомобиля", "Изменение статуса пользователя"
   - "Создание автомобиля", "Обновление автомобиля", "Удаление автомобиля"

### 2.12 Безопасность административного доступа

#### 2.12.1 Рекомендации по безопасности
1. Используйте надежные пароли и регулярно их меняйте
2. Не делитесь учетными данными администратора с другими лицами
3. Всегда выходите из административной панели после использования
4. Проверяйте логи действий на предмет подозрительной активности
5. Ограничьте количество пользователей с правами администратора

#### 2.12.2 Мониторинг активности
1. Регулярно просматривайте логи действий для выявления несанкционированных действий
2. Обращайте внимание на действия, выполненные в необычное время
3. Проверяйте изменения, внесенные другими администраторами
4. Ведите учет всех изменений, внесенных вручную в систему
