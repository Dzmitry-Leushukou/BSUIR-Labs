## 🎬 ПОШАГОВАЯ ИНСТРУКЦИЯ ДЛЯ СКРИНШОТОВ

### Для каждой ошибки:

1. **Открыть файл:**
   - Смотрите на файловую панель слева в VS Code
   - Найдите нужный файл (error1.idr, error2.idr, error3.idr, error4.idr)
   - Дважды кликните для открытия
   - Скриншот: **файл должен быть полностью виден**

2. **Запустить анализатор через терминал:**
   ```bash
   ./target/release/lab error1.idr  # (для error1, error2, error3, error4)
   ```

3. **Скриншот вывода:**
   - Должна быть видна команда `./ target/release/lab ...`
   - Должно быть видно сообщение об ошибке
   - Должны быть видны конкретные строка и колонка ошибки
   - **Пример скриншота:**
     ```
     $ ./target/release/lab error1.idr
     Лексическая ошибка в строке 2, колонка 5: unrecognized character '#'
     ```
