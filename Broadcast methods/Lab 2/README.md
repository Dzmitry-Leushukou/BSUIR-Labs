## 📝 Описание

Лексический анализатор читает исходный код на Idris 2 и выполняет следующие операции:

1. **Токенизация** - преобразование потока символов в поток лексем (токенов)
2. **Таблица имён** - сборка объединённой таблицы идентификаторов и констант
3. **Преобразование кода** - замена идентификаторов и констант на `<IDn>` ссылки
4. **Обнаружение ошибок** - детектирование лексических ошибок с указанием позиции

## ✨ Возможности

### Поддерживаемые лексемы

#### Ключевые слова (23)
```
module import if then else let where case of do 
forall \\ -> => :: type class instance data record 
in with syntax fix
```

#### Типы константы
- **Целые числа**: `42`, `-7`, `0`
- **Шестнадцатеричные**: `0x1F`, `0XABC` (с проверкой корректности)
- **Вещественные**: `3.14`, `.5`, `2.`
- **Научная нотация**: `1e-10`, `2.5E+3`, `3.14e5`
- **Строки**: `"hello"` (с экранированием: `\n`, `\t`, `\\`, `\"`, `\'`)
- **Символы**: `'a'`, `'n'` (с экранированием)

#### Операторы (15+)
```
+ - * / % ^ |> .
= == /= < > <= >= && || 
-> => :: .. << >>
```

#### Разделители
```
( ) { } [ ] : , ; = @
```

#### Комментарии
- **Однострочные**: `-- comment`
- **Многострочные**: `{- comment -}` (поддержка вложенности)

### Обработка ошибок

Детектирует и правильно обрабатывает:
1. **Нераспознанные символы** - чёрные символы вне допустимого набора
2. **Незакрытые строки** - переводы строк внутри строковых литералов
3. **Незакрытые комментарии** - многострочные комментарии без закрытия
4. **Синтаксические ошибки** - некорректная структура констант (0x без цифр и т.д.)

Все ошибки выводятся с указанием строки и колонки.

## 📚 Примеры

### Пример 1: Простое выражение

**Входной файл** (`example.idr`):
```idris
COST = (PRICE+TAX)*0.98
```

**Выход:**
```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | COST
2     | PRICE
3     | TAX
4     | 0.98

<ID1> = ( <ID2> + <ID3> ) * <ID4>
```

**Соответствие условию лаб:**
- ✅ COST, PRICE, TAX → идентификаторы
- ✅ 0.98 → константа (вещественное число)
- ✅ =, +, *, ( ) → операторы/разделители (без замены)
- ✅ Результат: `<ID1>=(<ID2>+<ID3>)*<ID4>` ✓

### Пример 2: Научная нотация

**Входной файл:**
```idris
x = 1e-10
y = 2.5E+3
z = 0xFF
```

**Выход:**
```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | x
2     | 1e-10
3     | y
4     | 2.5E+3
5     | z
6     | 0xFF

<ID1> = <ID2> <ID3> = <ID4> <ID5> = <ID6>
```

### Пример 3: Строки и символы

**Входной файл:**
```idris
msg = "hello\nworld"
ch = 'a'
```

**Выход:**
```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | msg
2     | "hello\nworld"
3     | ch
4     | 'a'

<ID1> = <ID2> <ID3> = <ID4>
```

## 🚨 Обработка ошибок

### Ошибка 1: Нераспознанный символ

```idris
x = 1 # error
```

**Вывод:**
```
Лексическая ошибка в строке 1, колонка 7: unrecognized character '#'
```

### Ошибка 2: Незакрытая строка

```idris
msg = "hello
next = 2
```

**Вывод:**
```
Лексическая ошибка в строке 1, колонка 19: unclosed string literal (newline not allowed)
```

### Ошибка 3: Незакрытый комментарий

```idris
x = 1
{- comment start
y = 2
```

**Вывод:**
```
Лексическая ошибка в строке 2, колонка 1: unclosed multi-line comment
```

### Ошибка 4: Некорректная константа

```idris
hex = 0x
```

**Вывод:**
```
Лексическая ошибка в строке 1, колонка 7: empty hexadecimal constant
```
