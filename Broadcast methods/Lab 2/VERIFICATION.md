## 🔍 Примеры вывода

### Пример 1: Единая таблица

**Входной код:**
```idris
module Main
x = 42
y = 3.14
```

**Выход:**
```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | Main
2     | x
3     | 42
4     | y
5     | 3.14

module <ID1> <ID2> = <ID3> <ID4> = <ID5>
```

### Пример 2: Операторы сохраняются

**Входной код:**
```idris
a => b -> c /= d
```

**Выход:**
```
...
4     | a
5     | b
6     | c
7     | d

<ID4> => <ID5> -> <ID6> /= <ID7>
```

### Пример 3: Научная нотация

**Входной код:**
```idris
x = 1e-10
y = 2.5E+3
```

**Выход:**
```
...
1     | x
2     | 1e-10
3     | y
4     | 2.5E+3

<ID1> = <ID2> <ID3> = <ID4>
```
