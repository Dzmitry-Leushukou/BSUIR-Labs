
```idris

```

- **Строка:** 2



### 📄 Содержимое:
```idris

x = 5
```

### ❌ Ошибка:
- **Строка:** 2
- **Колонка:** 7
- **Проблема:** Hexadecimal константа `0x` требует одну или более hex-цифр после неё (0-9, a-f, A-F)
- **Код:** `num = 0x` ← После `0x` должны быть цифры!

### 🖥️ Команда:
```bash
./target/release/lab error4.idr
```

### 📊 Вывод:
