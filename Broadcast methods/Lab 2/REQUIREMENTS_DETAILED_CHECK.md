## 1. ДЕДУПЛИКАЦИЯ ИДЕНТИФИКАТОРОВ И КОНСТАНТ ✅

**Требование:**
> "Если позднее во входной цепочке попадается идентификатор, надо справиться в этой таблице, не появлялся ли он ранее. Если да, то лексема, соответствующая новому вхождению этого идентификатора, будет той же, что и у предыдущего вхождения."

**Тест: `dedup_test.idr`**

```idris

y = 3.14    -- Первое появление y
x = 100     -- Второе появление x
z = x       -- Использование x
y = 2.71    -- Второе появление y
z = y       -- Использование y
msg = "hello"   -- Первое появление "hello"
msg2 = "hello"  -- Второе появление "hello"
num1 = 5        -- Первое появление 5
num2 = 5        -- Второе появление 5
num3 = 5        -- Третье появление 5
```

**Выход анализатора:**
```

ID  | Value
--- | ----

2   | 42
3   | y

Преобразованный код:
<ID1> = <ID2> <ID3> = <ID4> <ID1> = <ID5> <ID6> = <ID1> <ID3> = <ID7> <ID6> = <ID3> 
<ID8> = <ID9> <ID10> = <ID9> <ID11> = <ID12> <ID13> = <ID12> <ID14> = <ID12>
```

**Анализ дедупликации:**

| Элемент | Первое появление | Второе появление | ID | Статус |
|---------|------------------|------------------|-------|---------|
| x (строка 1) | `x = 42` → `<ID1> = <ID2>` | `x = 100` → `<ID1> = <ID5>` | **ID1** | ✅ Одинаковое |

| 5 (строка 9) | `num1 = 5` → `<ID11> = <ID12>` | `num2 = 5` → `<ID13> = <ID12>` | **ID12** | ✅ Одинаковое |
| 5 (строка 9) | `num1 = 5` → `<ID11> = <ID12>` | `num3 = 5` → `<ID14> = <ID12>` | **ID12** | ✅ Одинаковое |

## 2. ТАБЛИЦЫ В ИСХОДНОМ КОДЕ

### ✅ Таблица 1: КОНСТАНТЫ

**Структура:** `src/symbol_table.rs` → `ConstantTable` + `ConstantValue` enum

```rust
pub enum ConstantValue {
    Int(i64),        // 42, -5, 0
    Hex(u64),        // 0x1F, 0xFF
    Float(String),   // 3.14, 2.0e-5
    String(String),  // "hello"
    Char(String),    // 'a'
}

pub struct ConstantTable {
    constants: Vec<ConstantValue>,
    indices: HashMap<String, usize>,
}
```

**Поддерживаемые константы:**
- ✅ Целые числа (Int)
- ✅ Шестнадцатеричные числа (Hex)
- ✅ Вещественные числа и научная нотация (Float)
- ✅ Строки (String)
- ✅ Символы (Char)

**Дедупликация:** Через `canonical_key()` - каждый тип получает уникальный префикс (INT:, HEX:, FLOAT:, STRING:, CHAR:)

### ✅ Таблица 2: КЛЮЧЕВЫЕ СЛОВА

**Структура:** `src/token.rs` → `TokenType::Keyword(String)` + `src/lexer.rs` → `is_keyword()`

```rust
fn is_keyword(word: &str) -> bool {
    matches!(word,
        "module" | "import" | "if" | "then" | "else" | 
        "let" | "where" | "case" | "of" | "do" | 
        "forall" | "\\" | "type" | "class" | "instance" | 
        "data" | "record" | "in" | "with" | "syntax" | 
        "fix" | "implementation"
    )
}
```

**Поддерживаемые ключевые слова:** 23 шт
- module, import, if, then, else
- let, where, case, of, do
- forall, \, type, class, instance
- data, record, in, with, syntax, fix
- implementation

**Дедупликация:** Ключевые слова не добавляются в таблицу имён (они не заменяются на <IDn>, выводятся как есть)
