### ✅ 2. Поддержка всех требуемых элементов

**Требование из условия:**
```
Выражение может включать:
- Знаки сложения и умножения («+» и «*»)
- Круглые скобки («(» и «)»)
- Константы (например, 5; 3.8; 1e+18, 8.41E–10)
- Имена переменных
- Имя переменной – последовательность букв и цифр, начинающаяся с буквы
```

**Статус:** ✅ ВЫПОЛНЕНО

**Проверено на примере из условия:**
```
Входной файл: COST = (PRICE+TAX)*0.98
```

**Выход анализатора:**
```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | COST
2     | PRICE
3     | TAX
4     | 0.98

<ID1> = ( <ID2> + <ID3> ) * <ID4>
```

**Соответствие условию:**
- ✅ COST → <ID1> (идентификатор)
- ✅ PRICE → <ID2> (идентификатор)
- ✅ TAX → <ID3> (идентификатор)
- ✅ 0.98 → <ID4> (константа)
- ✅ = + * → выводятся как есть (лексемы)
- ✅ ( ) → выводятся как есть (разделители)

✅ Формат соответствует - номер | значение

### ✅ 5. Преобразование кода с заменой лексем

**Требование из условия:**
```
Все константы и идентификаторы отображаются в <ИД>:
COST = (PRICE+TAX)*0.98  →  <ИД1>=(<ИД2>+<ИД3>)*<ИД4>
```

**Статус:** ✅ ВЫПОЛНЕНО

**Реализация:**
- Основной цикл в main.rs
- Для каждого токена Identifier или константы: замена на `<IDn>`
- Операторы и разделители: выводятся как есть
- Токены разделены одним пробелом

**Пример:**
```
Входные токены: COST, =, (, PRICE, +, TAX, ), *, 0.98
Выход: <ID1> = ( <ID2> + <ID3> ) * <ID4>
```

**Требование из условия:**

**Статус:** ✅ ВЫПОЛНЕНО

### Тип ошибки 1: Нераспознанный символ

**Тестовый файл:** error1.idr
```idris
x = 1
a # b
```

**Выход:**
```
Лексическая ошибка в строке 2, колонка 5: unrecognized character '#'
```

✅ Ошибка обнаружена на символе #

---

### Тип ошибки 2: Незакрытая строка

**Тестовый файл:** error2.idr
```idris
x = 1
str = "hello
```

**Выход:**
```
Лексическая ошибка в строке 2, колонка 19: unclosed string literal (newline not allowed)
```

✅ Ошибка обнаружена: перевод строки внутри строки

---

### Тип ошибки 3: Незакрытый комментарий

**Тестовый файл:** error3.idr
```idris
x = 1

```

**Выход:**
```
Лексическая ошибка в строке 1, колонка 1: unclosed multi-line comment
```

✅ Ошибка обнаружена: комментарий не закрыт до конца файла

---

### Тип ошибки 4: Пустая hex-константа


**Выход:**

✅ Ошибка обнаружена: 0x без цифр
