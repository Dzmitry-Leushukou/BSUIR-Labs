### 1️⃣ ОШИБКА: Нераспознанный символ
- **Файл:** `error1.idr`
- **Содержимое:** `x = # 5`

- **Ошибка:** `Лексическая ошибка в строке 2, колонка 5: unrecognized character '#'`

### 2️⃣ ОШИБКА: Незакрытая строка
- **Файл:** `error2.idr`
- **Содержимое:** `str = "Hello world` (без закрывающего `"`)

- **Ошибка:** `Лексическая ошибка в строке 1, колонка 1: unclosed multi-line comment`

### 4️⃣ ОШИБКА: Пустая hex константа

## 📸 КАК СНЯТЬ СКРИНШОТЫ

### Для каждой ошибки:

1. **Откройте файл в VS Code:**
   ```
   Ctrl+P → введите error1.idr (error2.idr, error3.idr, error4.idr) → Enter
   ```

2. **Откройте встроенный терминал:**
   ```
   Ctrl+` (бектик) или Ctrl+J
   ```

3. **Запустите команду:**
   ```bash
   ./target/release/lab error1.idr
   ```
   (Замените error1.idr на error2.idr, error3.idr или error4.idr)

4. **Снимите скриншот:**
   - Файл должен быть виден с содержимым
   - Команда запуска должна быть видна
   - Сообщение об ошибке должно быть видно
   - **Используйте:** PrintScreen или Ctrl+Shift+S
