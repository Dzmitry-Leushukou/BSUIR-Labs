# ✅ Лексический анализатор Idris 2 - Версия 2 (завершена)

## 🎯 Что было сделано

Преподаватель требовал переделать вывод лексера так, чтобы он выглядел как на приложенном изображении. **Все требования выполнены:**

### 1️⃣ **Единая таблица "CONSTANTS AND IDENTS"**

Вместо двух отдельных таблиц теперь выводится **одна объединённая таблица** с общей нумерацией:

```
CONSTANTS AND IDENTS

ID    | Value
---   | ---
1     | Main
2     | Data
3     | Vect
4     | initialValue
5     | Int
6     | 42
7     | doubleValue
8     | Double
9     | 3.14159
...
```

✅ **Особенности:**
- Единая сквозная нумерация (идентификаторы и константы в одной таблице)
- Порядок: в порядке первого появления в коде
- Для идентификаторов: имя без кавычек
- Для чисел: литерал как в исходном коде (`0x1F`, `1e-10`, `2.`, и т.д.)
- Для строк: в двойных кавычках с экранированием (`"Hello\n"`)
- Для символов: в одинарных кавычках (`'a'`, `'\n'`)

### 2️⃣ **Преобразованный код**

После таблицы выводится **исходный код с заменой всех идентификаторов и констант на `<IDn>`**:

```
module <ID1> import <ID2> . <ID3> <ID4> : <ID5> <ID4> = <ID6> <ID7> : <ID8> ...
```

✅ **Особенности:**
- Все токены разделены ровно одним пробелом
- Составные операторы остаются одним токеном: `->`, `=>`, `::`, `/=`, это и т.д.
- Переводы строк игнорируются - всё выводится в одну строку
- Ключевые слова, операторы, разделители сохраняют исходный вид

### 3️⃣ **Обработка ошибок**

Если обнаружена ошибка:
- ✅ Выводятся только сообщения об ошибках
- ✅ Таблица и код **не выводятся**
- ✅ Программа завершается с кодом ошибки 1
- ✅ Формат: `Лексическая ошибка в строке N, колонка M: описание`

## 🔧 Основные исправления

### ✅ Исправлено парсинг научной нотации

**Проблема:** `1e-10` парсилось как три токена: `1`, `e`, `-10`

**Решение:** Удалено требование `is_float` из условия проверки экспоненты - теперь целые числа могут иметь экспоненту.

```rust
// Было:
if (self.current_char == Some('e') || self.current_char == Some('E')) && is_float {

// Стало:
if self.current_char == Some('e') || self.current_char == Some('E') {
    is_float = true; // Отмечаем как float
```

### ✅ Добавлена поддержка `_` (wildcard)

**Проблема:** `_` выводил ошибку "unrecognized character"

**Решение:** `_` теперь правильно распознаётся как начало идентификатора вместе с буквами.

```rust
// Было:
if ch.is_ascii_alphabetic() {

// Стало:
if ch.is_ascii_alphabetic() || ch == '_' {
```

### ✅ Исправлено распознавание оператора `/=`

**Проблема:** `/=` парсилось как два токена: `/` и `=`

**Решение:** Добавлена проверка на `=` после `/`, например как для `!=`.

```rust
// Добавлено:
'/' => {
    self.advance();
    if self.current_char == Some('=') {
        self.advance();
        TokenType::NotEqual  // /=
    } else {
        TokenType::Slash
    }
}
```
