# Лабораторная работа 4 — Семантический анализатор (Idris 2, Rust)

Проект реализует:
- лексический и синтаксический разбор выражений в правых частях определений;
- сбор сигнатур типов верхнего уровня (`name : Type`);
- построение таблицы символов;
- вывод/проверку типов выражений;
- проверку совместимости типов и сообщения о семантических ошибках;
- фиксацию неявных приведений типов (например, `Int -> Double`, `List a -> Vect n a`).

## Запуск

```bash
cargo run -- <путь_к_idr_файлу>
```

Пример:

```bash
cargo run -- tests_idr/lab3/program2_basics.idr
```

## Что выводится

1. Сводка по файлу: число определений, сигнатур, синтаксических и семантических ошибок.
2. Список синтаксических/семантических ошибок.
3. Найденные неявные приведения типов.
4. Типы выражений для разобранных определений.
5. Таблица символов (объявленный и выведенный тип, арность, строки сигнатуры/определения).
