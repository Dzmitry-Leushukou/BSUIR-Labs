# Лабораторная работа 5 — Интерпретация исходного кода (Idris 2, Rust)

Проект реализует полный конвейер для подмножества Idris 2:
- лексический анализ;
- синтаксический разбор выражений в правых частях определений;
- семантический анализ и проверку типов;
- компиляцию AST в байт-код;
- интерпретацию байт-кода (стековая VM).

База взята из лабораторных 2-4 и расширена интерпретатором для Lab 5.

## Поддерживаемые конструкции интерпретатора

- литералы: `Int`, `Double`, `String`, `Char`;
- списки;
- унарные операторы: `+`, `-`, `!`, `~`;
- бинарные операторы: `+`, `-`, `*`, `/`, `%`, `^`, `==`, `/=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `++`, `::`, `$`;
- применение функций, лямбда-выражения, частичное применение;
- операторные ссылки и правые секции (`(+)`, `(*2)`);
- простые верхнеуровневые определения вида `name p1 p2 = expr`.

## Ограничения

- сопоставление с образцом в левой части (`f [] = ...`, `f (x :: xs) = ...`) не интерпретируется и помечается предупреждением при сборке байт-кода;
- `do`-блоки, `case`, `if`, `where`, ввод-вывод Idris и зависимые конструкции вне поддерживаемого подмножества не исполняются VM.

## Запуск

```bash
cargo run -- <путь_к_idr_файлу> [--entry <имя>] [--eval-all] [--dump-bytecode]
```

Опции:
- `--entry <имя>`: имя точки входа для вычисления (по умолчанию `main`);
- `--eval-all`: вычислить все определения с арностью 0;
- `--dump-bytecode`: показать сгенерированный байт-код.

## Пример

```bash
cargo run -- tests_idr/lab5_interpreter_demo.idr --eval-all --dump-bytecode
```

В `tests_idr/lab5_interpreter_demo.idr` добавлен демонстрационный файл для проверки интерпретатора.
