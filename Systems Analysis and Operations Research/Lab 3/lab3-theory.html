Задача распределения ресурсов

Теория динамического программирования и подробный разбор программы на C++ простыми словами.

1. Что требуется найти

Есть Q одинаковых единиц ресурса и P агентов. Нужно распределить весь ресурс между агентами и получить как можно большую суммарную прибыль.

Прибыль каждого агента зависит от количества ресурса, которое он получил. Зависимость может быть любой: больше ресурса не обязательно означает больше прибыли. Например, агенту может быть выгодно получить 1 единицу, но невыгодно получать 2.

Все возможные прибыли записаны в матрице A. В ней P строк и Q+1 столбцов. Строка соответствует агенту, столбец с номером q показывает прибыль, если агент получил q единиц.

Важно: столбцы матрицы начинаются с нуля: первый столбец — прибыль при выделении 0 единиц, следующий — при 1 единице и так далее.

В примере ниже три агента и три единицы ресурса. Каждая строка после первой — прибыли одного агента для количеств ресурса от 0 до 3.

3 3
0 1 2 3
0 0 1 2
0 2 2 3

2. Идея динамического программирования

Вместо того чтобы сразу перебирать все полные распределения, решаем много маленьких задач и сохраняем ответы в таблице.

B(p,q) — это максимальная прибыль, которую можно получить, распределив q единиц ресурса между первыми p агентами.

Базовый случай: один агент

Если агент только один, то все q единиц, которые мы сейчас распределяем, получает он. Значит, прибыль уже записана в матрице A:

B(1, q) = A(1, q),    C(1, q) = q

C(p,q) запоминает решение: сколько единиц отдать агенту номер p, когда q единиц распределяются между первыми p агентами.

Остальные случаи: два агента или больше

Рассмотрим последнего из первых p агентов. Ему можно выделить i единиц, где i меняется от 0 до q. Тогда предыдущим агентам останется q-i единиц.

B(p, q) = max0 ≤ i ≤ q [ A(p, i) + B(p-1, q-i) ]

Для каждого допустимого i складываем две прибыли: прибыль текущего агента за i единиц и лучшую прибыль предыдущих агентов за остаток. Выбираем самый большой результат. Значение i, на котором получен максимум, записываем в C(p,q).

Проще говоря: пробуем отдать последнему агенту 0 единиц, затем 1, затем 2 и так далее. Каждый раз добавляем к его прибыли лучший результат для оставшегося ресурса. Побеждает самый выгодный вариант.

3. Пример из методички

Матрица прибыли:

Агент / ресурс0123
Агент 10123
Агент 20012
Агент 30223

Сначала агент 1

Первый агент получает весь ресурс в каждой маленькой задаче. Поэтому первая строка B совпадает с его строкой в A; строка C равна количеству ресурса:

B(1, ·) = 0, 1, 2, 3    C(1, ·) = 0, 1, 2, 3

Затем агент 2

Например, для двух единиц между первыми двумя агентами проверяем варианты:

отдать агенту 2: 0 → A(2,0)+B(1,2) = 0+2 = 2
отдать агенту 2: 1 → A(2,1)+B(1,1) = 0+1 = 1
отдать агенту 2: 2 → A(2,2)+B(1,0) = 1+0 = 1

Лучший вариант — прибыль 2, когда агент 2 получает 0. Поэтому B(2,2)=2 и C(2,2)=0. Так же считаются остальные ячейки строки.

Наконец агент 3

Для всех трёх единиц сравниваем:

агенту 3 дать 0: A(3,0)+B(2,3) = 0+3 = 3
агенту 3 дать 1: A(3,1)+B(2,2) = 2+2 = 4
агенту 3 дать 2: A(3,2)+B(2,1) = 2+1 = 3
агенту 3 дать 3: A(3,3)+B(2,0) = 3+0 = 3

Максимум равен 4. Он получается, если отдать третьему агенту 1 единицу. Следовательно, B(3,3)=4, C(3,3)=1.

Замечание по PDF: в текстовом разборе примера есть опечатка при вычислении B(2,3). По формуле значение равно 3, как указано в итоговой матрице B. Программа следует формуле и итоговой матрице.

4. Как восстановить распределение

Матрица B сообщает максимальную прибыль, но сама по себе не сообщает, кому сколько ресурса выдать. Для этого нужна матрица C.

  1. Начинаем с полной задачи: p=3, q=3.
  2. C(3,3)=1: агенту 3 выдаём 1 единицу. Осталось q=2.
  3. C(2,2)=0: агенту 2 выдаём 0 единиц. Осталось q=2.
  4. C(1,2)=2: агенту 1 выдаём оставшиеся 2 единицы.

Итог: агент 1 получает 2, агент 2 — 0, агент 3 — 1. Суммарная прибыль равна 4. Сумма выделенных ресурсов равна исходному запасу: 2+0+1=3.

5. Где это находится в программе

Структура Solution

В начале файла структура Solution хранит три таблицы/результата: best — матрица B; choice — матрица C; allocation — итоговое количество ресурса для каждого агента.

Функция solve

В solve находится основной алгоритм. Сначала создаются матрицы размера P × (Q+1). Затем заполняется базовая строка для первого агента. Вложенные циклы перебирают каждого следующего агента, каждое количество ресурса q и каждое возможное выделение i. Максимум попадает в best, а соответствующее выделение — в choice.

После заполнения таблиц функция проходит по choice с конца к началу, восстанавливая окончательный план. Это и есть обратный ход метода.

Функция main

main разбирает параметры запуска, читает P, Q и матрицу прибыли, проверяет корректность ввода, вызывает solve и печатает таблицы и план. Можно читать данные из стандартного ввода или указать имя файла аргументом программы. Флаг --detailed выводит каждую пару B(p,q), C(p,q).

Почему индексы в коде выглядят иначе

В методичке агенты пронумерованы от 1, а в C++ индексы вектора начинаются с 0. Поэтому агент 1 в формулах хранится как profit[0], агент p — как profit[p-1]. Столбец ресурса начинается с 0 и в коде, и в методичке.

6. Сколько занимает вычисление

Для каждой пары (p,q) перебираются значения i от 0 до q. Поэтому время работы — O(P × Q²). Таблицы B и C содержат по P × (Q+1) элементов, поэтому память — O(P × Q).

Суть всей программы в одной фразе: заполнить таблицу лучшей прибыли и таблицу решений, которые привели к этой прибыли, затем пройти по таблице решений назад и получить распределение.

7. Полный исходный код

Ниже приведён полный текст файла main.cpp, использованного для лабораторной работы.

#include <algorithm>
#include <cmath>
#include <fstream>
#include <iomanip>
#include <iostream>
#include <limits>
#include <sstream>
#include <string>
#include <vector>

using namespace std;

struct Solution {
    vector<vector<double>> best;
    vector<vector<int>> choice;
    vector<int> allocation;
};

static bool isInteger(double value) {
    return abs(value - round(value)) <= 1e-9;
}

static string formatNumber(double value) {
    ostringstream out;
    if (isInteger(value)) out << static_cast<long long>(llround(value));
    else out << fixed << setprecision(6) << value;
    return out.str();
}

static Solution solve(const vector<vector<double>>& profit) {
    const int agents = static_cast<int>(profit.size());
    const int resource = static_cast<int>(profit.front().size()) - 1;

    Solution result;
    result.best.assign(agents, vector<double>(resource + 1, 0.0));
    result.choice.assign(agents, vector<int>(resource + 1, 0));

    for (int q = 0; q <= resource; ++q) {
        result.best[0][q] = profit[0][q];
        result.choice[0][q] = q;
    }

    for (int p = 1; p < agents; ++p) {
        for (int q = 0; q <= resource; ++q) {
            double bestValue = -numeric_limits<double>::infinity();
            int bestChoice = 0;
            for (int assigned = 0; assigned <= q; ++assigned) {
                const double candidate = profit[p][assigned] + result.best[p - 1][q - assigned];
                // Scanning from zero keeps the first (smallest) allocation on ties.
                if (candidate > bestValue + 1e-9) {
                    bestValue = candidate;
                    bestChoice = assigned;
                }
            }
            result.best[p][q] = bestValue;
            result.choice[p][q] = bestChoice;
        }
    }

    result.allocation.assign(agents, 0);
    int remaining = resource;
    for (int p = agents - 1; p >= 0; --p) {
        result.allocation[p] = result.choice[p][remaining];
        remaining -= result.allocation[p];
    }
    return result;
}

static void printMatrix(const string& name, const vector<vector<double>>& matrix) {
    cout << "\n" << name << " (rows: agents, columns: q = 0..Q)\n";
    for (const auto& row : matrix) {
        for (double value : row) cout << setw(12) << formatNumber(value);
        cout << '\n';
    }
}

static void printChoiceMatrix(const vector<vector<int>>& matrix) {
    cout << "\nC (amount assigned to the current agent)\n";
    for (const auto& row : matrix) {
        for (int value : row) cout << setw(12) << value;
        cout << '\n';
    }
}

int main(int argc, char* argv[]) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    bool detailed = false;
    string filename;
    for (int i = 1; i < argc; ++i) {
        const string argument = argv[i];
        if (argument == "--detailed") detailed = true;
        else if (filename.empty()) filename = argument;
        else {
            cerr << "Usage: " << argv[0] << " [--detailed] [input_file]\n";
            return 2;
        }
    }

    ifstream input;
    if (!filename.empty()) {
        input.open(filename);
        if (!input) {
            cerr << "Cannot open input file: " << filename << '\n';
            return 2;
        }
        cin.rdbuf(input.rdbuf());
    }

    int agents = 0;
    int resource = 0;
    if (!(cin >> agents >> resource) || agents <= 0 || resource < 0) {
        cerr << "Input error: expected P > 0 and Q >= 0.\n";
        return 2;
    }

    vector<vector<double>> profit(agents, vector<double>(resource + 1));
    for (int p = 0; p < agents; ++p) {
        for (int q = 0; q <= resource; ++q) {
            if (!(cin >> profit[p][q]) || !isfinite(profit[p][q])) {
                cerr << "Input error: expected a P x (Q + 1) profit matrix.\n";
                return 2;
            }
        }
    }

    string extra;
    if (cin >> extra) {
        cerr << "Input error: unexpected data after the profit matrix.\n";
        return 2;
    }

    const Solution result = solve(profit);

    cout << "Resource Allocation Problem - Dynamic Programming\n";
    cout << "=================================================\n";
    cout << "Agents (P): " << agents << ", resource units (Q): " << resource << '\n';
    cout << "Input matrix A: profit for each agent and allocated amount\n";
    printMatrix("A", profit);
    printMatrix("B (maximum profit)", result.best);
    printChoiceMatrix(result.choice);

    cout << "\nOptimal allocation (backward pass):\n";
    int totalUnits = 0;
    for (int p = 0; p < agents; ++p) {
        cout << "  Agent " << p + 1 << ": " << result.allocation[p] << " unit(s)\n";
        totalUnits += result.allocation[p];
    }
    cout << "Total allocated: " << totalUnits << " of " << resource << '\n';
    cout << "Maximum total profit B(P, Q) = " << formatNumber(result.best.back().back()) << '\n';

    if (detailed) {
        cout << "\nDetailed recurrence values:\n";
        for (int p = 1; p <= agents; ++p) {
            for (int q = 0; q <= resource; ++q) {
                cout << "B(" << p << ", " << q << ") = "
                     << formatNumber(result.best[p - 1][q])
                     << ", C(" << p << ", " << q << ") = "
                     << result.choice[p - 1][q] << '\n';
            }
        }
    }
    return 0;
}
