Подробная теория и разбор кода

Поиск наидлиннейшего пути в ориентированном ациклическом графе

Объяснение того, что решает лабораторная работа, почему алгоритм работает и за что отвечает каждый основной блок программы на C++.

Динамическое программирование Топологическая сортировка Восстановление пути

1. Постановка задачи

Дан ориентированный граф. Каждая дуга имеет целую неотрицательную длину. В графе нет контуров, то есть нет направленных циклов. Заданы начальная вершина s и конечная вершина t.

Нужно выяснить, можно ли попасть из s в t. Если можно, требуется найти путь с наибольшей суммой длин дуг.

Что значит «самый длинный путь»? Берём каждый возможный путь от s к t, складываем длины его дуг и выбираем путь с максимальной суммой.

2. Главная идея

Если в графе нет циклов, вершины можно расположить в таком порядке, чтобы каждая дуга шла только от более ранней вершины к более поздней. Такой порядок называется топологическим.

v1 ──5──▶ v2 ──4──▶ v4 ──3──▶ v6
 │                    ▲              ▲
 ├──3──▶ v3 ──2───────┘              │
 └──────────────────▶ v2              │
            v2 ──2──▶ v5 ─────7───────┘

Схематичный пример. На каждой дуге указана её длина. Вершины можно обработать слева направо.

После топологической сортировки программа идёт по вершинам от s к t. К моменту обработки очередной вершины уже известны лучшие пути до всех вершин, из которых в неё входят дуги. Поэтому для неё остаётся сравнить несколько вариантов и выбрать лучший.

Аналогия Представь, что в каждую вершину записывается лучший результат, с которым до неё можно добраться. Когда рассматриваем новую вершину, проверяем все входы в неё: «если прийти через этот вход, какой получится результат?» Оставляем максимальный.

Если вершина недостижима из s, её значение OPT считается равным минус бесконечности. В C++ используется очень маленькое число NEGATIVE_INFINITY, потому что обычные типы чисел не хранят математическую бесконечность так, как нужна этой программе.

4. Алгоритм по шагам

Считать графПолучить число вершин и дуг, вершины s и t, затем все дуги с длинами.
Проверить графУбедиться, что номера вершин корректны, длины неотрицательные, а циклов нет.
Упорядочить вершиныПостроить топологический порядок, в котором каждая дуга идёт вперёд.
Сравнить позицииЕсли s стоит после t, путь из s в t невозможен.
Выполнить прямой ходДля вершин между s и t вычислить OPT и запомнить предшественника.
Выполнить обратный ходНачать с t и переходить к сохранённым предшественникам, пока не дойдём до s.

Начальная формула

OPT(vk) = 0

В начальной вершине мы уже находимся, поэтому длина пути до неё равна нулю.

Формула перехода

OPT(vi) = max(vj, vi) ∈ A [ OPT(vj) + l(vj, vi) ]

Чтобы найти лучший путь в v_i, рассматриваем каждую дугу, входящую в v_i. Для каждой такой дуги прибавляем её длину к лучшему пути до её начала. Из всех вариантов выбираем максимальный.

Вершину, через которую получился максимум, записываем как x(v_i). Она понадобится, чтобы потом восстановить путь.

6. Полный исходный код программы

Ниже приведён весь текущий файл main.cpp целиком. Код встроен в эту страницу напрямую, поэтому его можно читать вместе с пояснениями выше.

#include <algorithm>
#include <fstream>
#include <functional>
#include <iostream>
#include <limits>
#include <queue>
#include <stdexcept>
#include <string>
#include <vector>

using namespace std;

const long long NEGATIVE_INFINITY = numeric_limits<long long>::lowest() / 4;

struct Edge {
    int from;
    int to;
    long long length;
};

struct Graph {
    int vertexCount = 0;
    int edgeCount = 0;
    int source = 0;
    int target = 0;
    vector<Edge> edges;
    vector<vector<int>> outgoing;
    vector<vector<int>> incoming;
};

Graph readGraph(istream& input) {
    Graph graph;
    if (!(input >> graph.vertexCount >> graph.edgeCount))
        throw runtime_error("Input error: expected vertex and edge counts (n m).");
    if (graph.vertexCount <= 0 || graph.edgeCount < 0)
        throw runtime_error("Input error: n must be positive and m must be non-negative.");

    if (!(input >> graph.source >> graph.target))
        throw runtime_error("Input error: expected source and target vertices (s t).");
    if (graph.source < 1 || graph.source > graph.vertexCount ||
        graph.target < 1 || graph.target > graph.vertexCount)
        throw runtime_error("Input error: source and target must be in the range 1..n.");
    if (graph.source == graph.target)
        throw runtime_error("Input error: source and target vertices must be different.");

    --graph.source;
    --graph.target;
    graph.outgoing.assign(graph.vertexCount, {});
    graph.incoming.assign(graph.vertexCount, {});
    graph.edges.reserve(graph.edgeCount);

    for (int i = 0; i < graph.edgeCount; ++i) {
        int from, to;
        long long length;
        if (!(input >> from >> to >> length))
            throw runtime_error("Input error: every arc must contain from, to and length.");
        if (from < 1 || from > graph.vertexCount || to < 1 || to > graph.vertexCount)
            throw runtime_error("Input error: arc endpoint is outside the range 1..n.");
        if (length < 0)
            throw runtime_error("Input error: arc lengths must be non-negative.");

        --from;
        --to;
        graph.edges.push_back({from, to, length});
        graph.outgoing[from].push_back(i);
        graph.incoming[to].push_back(i);
    }

    string extra;
    if (input >> extra)
        throw runtime_error("Input error: unexpected data after the arc list.");
    return graph;
}

vector<int> topologicalOrder(const Graph& graph) {
    vector<int> indegree(graph.vertexCount, 0);
    for (const Edge& edge : graph.edges) ++indegree[edge.to];

    priority_queue<int, vector<int>, greater<int>> ready;
    for (int vertex = 0; vertex < graph.vertexCount; ++vertex)
        if (indegree[vertex] == 0) ready.push(vertex);

    vector<int> order;
    order.reserve(graph.vertexCount);
    while (!ready.empty()) {
        int vertex = ready.top();
        ready.pop();
        order.push_back(vertex);
        for (int edgeIndex : graph.outgoing[vertex]) {
            const Edge& edge = graph.edges[edgeIndex];
            if (--indegree[edge.to] == 0) ready.push(edge.to);
        }
    }

    if ((int)order.size() != graph.vertexCount)
        throw runtime_error("Input error: the graph contains a directed cycle.");
    return order;
}

void printPath(const vector<int>& path) {
    for (int i = 0; i < (int)path.size(); ++i) {
        if (i) cout << " -> ";
        cout << path[i] + 1;
    }
    cout << '\n';
}

int main(int argc, char* argv[]) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string filename;
    for (int i = 1; i < argc; ++i) {
        string argument = argv[i];
        if (!filename.empty()) {
            cerr << "Usage: " << argv[0] << " [input_file]\n";
            return 2;
        }
        filename = argument;
    }

    ifstream inputFile;
    if (!filename.empty()) {
        inputFile.open(filename);
        if (!inputFile) {
            cerr << "Cannot open input file: " << filename << '\n';
            return 2;
        }
    }
    istream& input = filename.empty() ? cin : inputFile;

    try {
        Graph graph = readGraph(input);
        vector<int> order = topologicalOrder(graph);

        vector<int> position(graph.vertexCount, -1);
        for (int i = 0; i < graph.vertexCount; ++i)
            position[order[i]] = i;

        int sourcePosition = position[graph.source];
        int targetPosition = position[graph.target];

        vector<long long> opt(graph.vertexCount, NEGATIVE_INFINITY);
        vector<int> predecessor(graph.vertexCount, -1);
        opt[graph.source] = 0; // (1) OPT(v_k) = 0.

        if (sourcePosition <= targetPosition) {
            // (2) OPT(v_i) = max(OPT(v_t) + l(v_t, v_i)) over incoming arcs.
            for (int orderIndex = sourcePosition + 1;
                 orderIndex <= targetPosition; ++orderIndex) {
                int vertex = order[orderIndex];
                for (int edgeIndex : graph.incoming[vertex]) {
                    const Edge& edge = graph.edges[edgeIndex];
                    if (opt[edge.from] == NEGATIVE_INFINITY) continue;
                    long long candidate = opt[edge.from] + edge.length;
                    if (candidate > opt[vertex]) {
                        opt[vertex] = candidate;
                        predecessor[vertex] = edge.from; // x(v_i).
                    }
                }
            }
        }

        cout << "Longest path in a directed acyclic graph\n";
        cout << "==========================================\n";
        cout << "Vertices: " << graph.vertexCount << ", arcs: " << graph.edgeCount << '\n';
        cout << "Source: v" << graph.source + 1 << ", target: v" << graph.target + 1 << '\n';
        cout << "Topological order: ";
        for (int i = 0; i < (int)order.size(); ++i) {
            if (i) cout << ' ';
            cout << order[i] + 1;
        }
        cout << '\n';
        if (sourcePosition > targetPosition) {
            cout << "\nSince k > l, target v" << graph.target + 1
                 << " is before source v" << graph.source + 1
                 << " in the topological order, so it is unreachable.\n";
            return 0;
        }

        cout << "\nForward pass (OPT(v_i), x(v_i)):\n";
        for (int orderIndex = sourcePosition; orderIndex <= targetPosition; ++orderIndex) {
            int vertex = order[orderIndex];
            cout << "OPT(v" << vertex + 1 << ") = ";
            if (opt[vertex] == NEGATIVE_INFINITY) cout << "-inf";
            else cout << opt[vertex];
            if (vertex == graph.source) {
                cout << ", x(v" << vertex + 1 << ") = -";
            } else if (predecessor[vertex] != -1) {
                cout << ", x(v" << vertex + 1 << ") = v" << predecessor[vertex] + 1;
            } else {
                cout << ", x(v" << vertex + 1 << ") = -";
            }
            cout << '\n';
        }

        if (opt[graph.target] == NEGATIVE_INFINITY) {
            cout << "\nResult: vertex v" << graph.target + 1
                 << " is unreachable from v" << graph.source + 1 << ".\n";
            return 0;
        }

        vector<int> path;
        for (int vertex = graph.target; vertex != -1; vertex = predecessor[vertex])
            path.push_back(vertex);
        reverse(path.begin(), path.end());

        cout << "\nResult:\n";
        cout << "Backward pass: ";
        for (int i = (int)path.size() - 1; i >= 0; --i) {
            if (i != (int)path.size() - 1) cout << " -> ";
            cout << path[i] + 1;
        }
        cout << "\nLongest path: ";
        printPath(path);
        cout << "Path length: " << opt[graph.target] << '\n';
    } catch (const exception& error) {
        cerr << error.what() << '\n';
        return 1;
    }

    return 0;
}

7. Формат входных данных

Методичка описывает математическую задачу, но не задаёт формат текстового файла. В программе используется такой формат:

n m
s t
from1 to1 length1
from2 to2 length2
...
from_m to_m length_m

Например, строка 2 5 2 означает дугу из вершины 2 в вершину 5 длины 2. Нумерация во входном файле начинается с единицы.

Почему программа проверяет вход Если вершины указаны вне диапазона, дуга имеет отрицательную длину или граф содержит цикл, вход не соответствует условиям задачи. Программа сообщает об этом и не выдаёт результат, которому нельзя доверять.

9. Почему алгоритм верный

  1. Рассматриваются все возможные последние дуги. Любой путь, который заканчивается в v_i, должен прийти туда по одной из дуг, входящих в v_i.
  2. Для каждого варианта берётся лучший предыдущий путь. Если путь приходит по дуге v_j -> v_i, его лучшая возможная длина равна OPT(v_j) + l(v_j, v_i).
  3. Выбирается максимальный вариант. Формула сравнивает все входящие дуги и сохраняет наибольшую длину.
  4. Нужные значения уже вычислены. В топологическом порядке начало каждой дуги стоит раньше конца. Значит, OPT(v_j) готово до того, как алгоритм обрабатывает v_i.
  5. Предшественники восстанавливают выбранный путь. Каждое значение x(v_i) указывает на вершину, которая дала максимум. Переходя по ним назад, приходим к s.

10. Сложность

Топологическая сортировка обрабатывает каждую вершину и каждую дугу ограниченное число раз. Динамическое программирование также просматривает вершины и входящие в них дуги.

РесурсСложностьЧто это означает
ВремяO(n + m)Время растёт примерно пропорционально размеру графа.
ПамятьO(n + m)Хранятся вершины, дуги и вспомогательные списки.

11. Короткий ответ для защиты

В программе реализован алгоритм динамического программирования для поиска наидлиннейшего пути в ориентированном ациклическом графе. Сначала строится топологический порядок вершин. Затем для начальной вершины полагается OPT(s) = 0, а для каждой следующей вершины вычисляется максимум по всем входящим дугам: OPT(v) = max(OPT(u) + l(u, v)). Вершина, через которую получен максимум, сохраняется как предшественник. После вычисления значения для конечной вершины путь восстанавливается обратным переходом по предшественникам.

Если попросят объяснить, почему не перебираются все пути

В DAG топологический порядок позволяет обработать каждую вершину один раз после всех её предшественников. Для каждой вершины достаточно сравнить входящие дуги. Поэтому перебор всех путей не нужен.

Если попросят объяснить минус бесконечность

Это метка «пока нет пути из начальной вершины». Она не позволяет случайно использовать недостижимую вершину в формуле перехода.
