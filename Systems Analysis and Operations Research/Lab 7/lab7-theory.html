1. Идея задачи

Представь, что есть несколько работников и столько же заданий. Каждая клетка таблицы показывает, сколько будет стоить назначить конкретного работника на конкретное задание. Нужно распределить задания так, чтобы каждый работник получил ровно одно задание, каждое задание досталось ровно одному работнику, а общая стоимость была как можно меньше.

Найти перестановку π, минимизирующую сумму C1,π(1) + C2,π(2) + … + Cn,π(n).

Строка означает работника, столбец означает задание, число в клетке означает стоимость пары. В программе роли могут быть любыми: например, строки — это станки, а столбцы — работы.

Почему нельзя просто брать минимум в каждой строке? Потому что минимумы могут оказаться в одном столбце. Тогда одному заданию соответствовали бы сразу несколько работников, а другому не соответствовал бы никто. Алгоритм ищет назначения одновременно, учитывая все строки и столбцы.

2. Обозначения простыми словами

CijСтоимость назначения строки i в столбец j; это число из входной матрицы.
αi (альфа)Потенциал строки i. В начале все альфы равны нулю.
βj (бета)Потенциал столбца j. В начале это минимальная стоимость в столбце j.
J=Клетки, где αi + βj = Cij. Они становятся рёбрами графа для назначений.
J<Клетки, где αi + βj < Cij. В них пока остаётся положительный запас.
MТекущие назначения без повторения строк и столбцов. Максимальное паросочетание содержит как можно больше таких пар.
I*, J*Строки и столбцы, достижимые в чередующемся обходе графа от неназначенных строк.
θ (тета)Половина минимального запаса среди строк I* и столбцов вне J*. Она определяет изменение потенциалов.

Индексы в программе. В методичке строки и столбцы нумеруются с 1. В C++ векторы нумеруются с 0. Поэтому, например, строка с индексом 0 печатается как строка 1: в выводе к индексу прибавляется единица.

3. Алгоритм по шагам методички

  1. Получить начальные потенциалы. Для всех строк положить αi = 0. Для каждого столбца положить βj равным минимальному числу в этом столбце. Тогда α + β не превосходит стоимости ни в одной клетке.
  2. Разделить клетки на равенства и строгие неравенства. Если αi + βj = Cij, клетка относится к J=. Иначе, поскольку потенциалы допустимы, получается αi + βj < Cij, то есть клетка относится к J<.
  3. Построить двудольный граф. Слева находятся строки, справа — столбцы. Ребро между строкой и столбцом есть только тогда, когда их клетка принадлежит J=.
  4. Найти максимальное паросочетание M. Это максимально возможный набор рёбер, у которых не повторяется ни одна строка и ни один столбец. Каждое ребро — одно назначение.
  5. Проверить размер M. Если в M ровно n рёбер, все строки и столбцы назначены. Это оптимум, алгоритм останавливается.
  6. Если назначений меньше n, пройти ориентированный граф. Начать со всех строк без назначения. Из строки идти по рёбрам, которые не входят в M, из столбца — по ребру M обратно к строке. Все достигнутые строки образуют I*, достигнутые столбцы — J*.
  7. Вычислить θ. Рассмотреть клетки со строкой из I* и столбцом вне J*. Для каждой взять половину запаса Cij − αi − βj. θ — наименьшее из этих значений.
  8. Обновить потенциалы. На строках из I* прибавить θ к α, на остальных строках вычесть θ. На столбцах из J* вычесть θ из β, на остальных столбцах прибавить θ. Клетки, на которых достигается минимум при вычислении θ, становятся новыми равенствами. Повторить со шага 2.
θ = mini ∈ I*, j ∉ J* (Cij − αi − βj) / 2

Деление на два здесь именно такое, как в методичке. Потенциал строки и потенциал столбца меняются одновременно, поэтому запас между их суммой и стоимостью уменьшается на 2θ.

Самая важная функция — augment

Функция получает одну строку и ищет среди её рёбер равенства свободный столбец. Если столбец занят другой строкой, она рекурсивно пробует переселить прежнюю строку в другой столбец. Например, было «строка 1 → столбец 2», а строке 2 тоже нужен столбец 2. Функция ищет для строки 1 другой допустимый столбец, освобождает столбец 2 и назначает его строке 2. Так размер паросочетания может увеличиться.

Как код строит I* и J*

Массив matchedRow отвечает на вопрос «какая строка сейчас заняла этот столбец?». Сначала программа находит строки, у которых нет назначения, и кладёт их в очередь. Затем обходит рёбра равенства, не входящие в M, к столбцам. Если такой столбец занят, программа идёт по его выбранному ребру обратно к строке. Очередь нужна, чтобы обработать все достижимые строки, а не только одну цепочку.

Зачем EPS и long double

Потенциалы могут стать дробными, например 0.5. Дробные числа компьютер хранит приближённо, поэтому вместо точного сравнения «равно» код проверяет, что абсолютная разница не больше EPS = 10−10. Тип long double даёт дополнительную точность для вычислений.

6. Почему это действительно минимум

Потенциалы всегда поддерживают условие αi + βj ≤ Cij. Возьмём любое допустимое назначение. В нём используется ровно один элемент каждой строки и ровно один элемент каждого столбца. Поэтому сумма стоимостей этого назначения не меньше суммы всех потенциалов:

Стоимость любого назначения ≥ Σi αi + Σj βj.

Когда найдено паросочетание размера n по рёбрам J=, каждая назначенная клетка удовлетворяет равенству Cij = αi + βj. Поэтому стоимость именно этого назначения равна сумме потенциалов. Оно достигает нижней границы, которую не может превзойти никакое другое допустимое назначение. Следовательно, найденное решение оптимально.

В PDF с примером некоторые списки рёбер равенства могут быть сокращены или содержать опечатку. Код строит J= непосредственно по формуле α + β = C. Например, после обновления потенциалов из примера равенства для второй строки могут появиться не только в перечисленных в тексте примера клетках. Проверка по формуле важнее ручного списка.
