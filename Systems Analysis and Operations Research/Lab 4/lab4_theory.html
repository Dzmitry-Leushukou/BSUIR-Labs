Лабораторная работа 4: задача о целочисленном рюкзаке

Подробное объяснение постановки, динамического программирования и того, где каждая часть алгоритма находится в программе на C++.

1. Идея задачи

Есть рюкзак вместимостью B и n предметов. У предмета i есть объём vᵢ и ценность cᵢ. Каждый предмет можно взять максимум один раз.

Нужно выбрать предметы так, чтобы суммарный объём не превысил вместимость, а суммарная ценность была максимальной:

∑ vᵢxᵢ ≤ B,   xᵢ ∈ {0, 1};
максимизировать   ∑ cᵢxᵢ.

xᵢ = 1 означает, что предмет выбран, а xᵢ = 0 — что предмет не выбран.

Пример. При вместимости 7 предметы 2 и 3 занимают 3 + 4 = 7 места и дают ценность 4 + 5 = 9. Поэтому для примера из файла ответом является вектор (0, 1, 1, 0).

2. Почему используется динамическое программирование

Прямой перебор проверяет все наборы предметов. Для n предметов это до 2ⁿ вариантов, что быстро становится слишком медленно.

Динамическое программирование разбивает большую задачу на маленькие. Мы не решаем одну и ту же подзадачу повторно, а сохраняем уже найденный ответ в таблице.

Состояние обозначается OPT(k, b):

OPT(k, b) — максимальная ценность, которую можно получить, используя только первые k предметов при вместимости b.

Индексы k и b — это не номера массива, а смысл состояния. В C++ таблица начинается с нуля, поэтому в ней есть строка для k = 0 и столбец для b = 0.

3. Рекуррентная формула

Рассмотрим предмет k. У него объём vₖ и ценность cₖ. Есть два варианта.

Предмет не берём

Тогда остаются первые k − 1 предметов и прежняя вместимость:

OPT(k − 1, b)

Предмет берём

Это возможно только если vₖ ≤ b. После взятия предмета остаётся вместимость b − vₖ:

OPT(k − 1, b − vₖ) + cₖ

Выбираем лучший вариант

OPT(k, b) = OPT(k − 1, b), если vₖ > b;
OPT(k, b) = max(OPT(k − 1, b), OPT(k − 1, b − vₖ) + cₖ), если vₖ ≤ b.

В таблице x(k,b) программа запоминает, был ли выбран предмет k. В методичке предмет выбирается только при строгом улучшении:

x(k,b) = 1, если вариант «взять» строго лучше варианта «не брать»; иначе x(k,b) = 0.

4. Как читается вход

Файл input.txt имеет формат:

n B
v1 c1
v2 c2
...
vn cn

Текущий пример:

4 7
1 1
3 4
4 5
5 7

Это означает: 4 предмета, вместимость 7. Далее идут пары «объём, ценность».

Структура входной задачи

struct Problem {
    int itemCount;
    int capacity;
    vector<int> volume;
    vector<Value> cost;
};

volume[i] хранит объём предмета, а cost[i] — его ценность. В математике предметы нумеруются с 1, а в C++ вектор начинается с 0, поэтому для предмета k используется индекс k - 1.

Problem readProblem(istream& input) {
    long long n = 0;
    long long capacity = 0;

    if (!(input >> n >> capacity))
        throw runtime_error("Input error: expected item count and backpack capacity: n B.");

    if (n <= 0 || n > numeric_limits<int>::max())
        throw runtime_error("Input error: n must be a positive integer.");

    if (capacity < 0 || capacity > numeric_limits<int>::max())
        throw runtime_error("Input error: B must be a non-negative integer.");

    Problem problem{
        static_cast<int>(n),
        static_cast<int>(capacity),
        vector<int>(static_cast<size_t>(n)),
        vector<Value>(static_cast<size_t>(n))
    };

    for (int i = 0; i < problem.itemCount; ++i) {
        long long volume = 0;
        long long value = 0;
        if (!(input >> volume >> value))
            throw runtime_error("Input error: expected n pairs volume_i value_i.");

        if (volume < 0 || volume > numeric_limits<int>::max())
            throw runtime_error("Input error: item volumes must be non-negative integers.");
        if (value < 0)
            throw runtime_error("Input error: item values must be non-negative integers.");

        problem.volume[i] = static_cast<int>(volume);
        problem.cost[i] = value;
    }

    return problem;
}

5. Таблицы алгоритма

Результат хранится в структуре:

struct Solution {
    vector<vector<Value>> optimum;
    vector<vector<unsigned char>> take;
    vector<int> selected;
    int usedCapacity = 0;
    Value totalValue = 0;
};

optimum — таблица OPT(k,b). take — таблица x(k,b), где 1 означает «предмет выбран», а 0 — «предмет не выбран».

solution.optimum.assign(n + 1, vector<Value>(B + 1, 0));
solution.take.assign(n + 1, vector<unsigned char>(B + 1, 0));

Плюс один нужен для базовых состояний:

  • OPT(0,b) = 0: предметов нет;
  • OPT(k,0) = 0: вместимость равна нулю.

6. Прямой ход: заполнение таблиц

Внешний цикл перебирает предметы, внутренний — все возможные вместимости:

for (int k = 1; k <= n; ++k) {
    const int volume = problem.volume[k - 1];
    const Value value = problem.cost[k - 1];

    for (int b = 0; b <= B; ++b) {
        ...
    }
}

В каждой ячейке сначала записывается вариант «не брать предмет»:

const Value skip = solution.optimum[k - 1][b];
solution.optimum[k][b] = skip;

Если предмет помещается, считается вариант «взять предмет»:

if (volume <= b) {
    const Value choose =
        solution.optimum[k - 1][b - volume] + value;

    if (choose > skip) {
        solution.optimum[k][b] = choose;
        solution.take[k][b] = 1;
    }
}

Переменная skip — ценность без текущего предмета. Переменная choose — ценность при взятии текущего предмета. Если choose больше, в таблицу записывается этот вариант и ставится отметка take = 1.

Для ячейки OPT(3,7): предмет 3 имеет объём 4 и ценность 5. Не брать его: OPT(2,7) = 5. Взять его: OPT(2,3) + 5 = 4 + 5 = 9. Выбирается 9, поэтому take[3][7] = 1.

7. Обратный ход: восстановление предметов

Последняя ячейка OPT(n,B) сообщает максимальную ценность, но сама по себе не перечисляет предметы. Для этого программа идёт по таблице take снизу вверх.

int remaining = B;

for (int k = n; k >= 1; --k) {
    if (!solution.take[k][remaining])
        continue;

    solution.selected.push_back(k);
    remaining -= problem.volume[k - 1];
}

Если take[k][remaining] == 0, предмет не выбран и мы просто переходим к предыдущему предмету. Если значение равно 1, предмет выбран, поэтому его объём вычитается из оставшейся вместимости.

В примере обратный ход выглядит так:

  1. Проверяем предмет 4 в состоянии (4,7): не выбран.
  2. Проверяем предмет 3 в состоянии (3,7): выбран. Остаток становится 7 − 4 = 3.
  3. Проверяем предмет 2 в состоянии (2,3): выбран. Остаток становится 3 − 3 = 0.
  4. Предмет 1 уже не может добавить ценность.

Так как обратный ход находит предметы с конца, сначала список получается как 3, 2. Команда ниже разворачивает его:

reverse(solution.selected.begin(), solution.selected.end());

После разворота выводится привычный порядок: 2, 3.

8. Что выводит программа

cout << "Maximum value: "
     << solution.optimum[problem.itemCount][problem.capacity]
     << '\n';

Это значение OPT(n,B), то есть ответ всей задачи.

cout << "Selected items (1-based): ";
for (size_t i = 0; i < solution.selected.size(); ++i) {
    if (i != 0) cout << ", ";
    cout << solution.selected[i];
}

Программа также строит вектор решений:

Decision vector x = (0, 1, 1, 0)

Это означает:

ПредметxᵢРешение
10не брать
21взять
31взять
40не брать
Проверка решения: объём 3 + 4 = 7, ценность 4 + 5 = 9. Ограничение по вместимости выполнено, ценность максимальна.

9. Что делает main

Функция main принимает аргументы командной строки:

main.exe input.txt
main.exe --detailed input.txt

Флаг --detailed включает печать таблиц OPT и x. Сам алгоритм выполняется в обоих режимах.

const Problem problem = readProblem(cin);
const Solution solution = solveKnapsack(problem);

if (detailed)
    printTable(problem, solution);

printResult(problem, solution);

Вызов cin.rdbuf(inputFile.rdbuf()) позволяет использовать один и тот же код чтения независимо от того, вводятся данные вручную или берутся из файла.

10. Сложность алгоритма

Внешний цикл выполняется n раз, внутренний — B + 1 раз. Поэтому:

Время: O(nB)     Память: O(nB)

Полный перебор имеет сложность O(2ⁿ). Динамическое программирование выигрывает за счёт того, что сохраняет ответы для уже решённых состояний.

Ограничение подхода: память и время зависят от вместимости B. Если B огромная, таблица тоже будет большой. Для учебной задачи это нормальный и ожидаемый алгоритм.

11. Основной код программы

Ниже код вставлен непосредственно в HTML, чтобы теорию можно было читать без переходов к другим файлам. Все ключевые фрагменты полного исходника разобраны по разделам выше.

#include <algorithm>
#include <fstream>
#include <iomanip>
#include <iostream>
#include <limits>
#include <stdexcept>
#include <string>
#include <vector>

using namespace std;
using Value = long long;

struct Problem {
    int itemCount;
    int capacity;
    vector<int> volume;
    vector<Value> cost;
};

struct Solution {
    vector<vector<Value>> optimum;
    vector<vector<unsigned char>> take;
    vector<int> selected;
    int usedCapacity = 0;
    Value totalValue = 0;
};

Problem readProblem(istream& input) {
    long long n = 0;
    long long capacity = 0;
    if (!(input >> n >> capacity))
        throw runtime_error("Input error: expected item count and backpack capacity: n B.");
    if (n <= 0 || n > numeric_limits<int>::max())
        throw runtime_error("Input error: n must be a positive integer.");
    if (capacity < 0 || capacity > numeric_limits<int>::max())
        throw runtime_error("Input error: B must be a non-negative integer.");

    Problem problem{
        static_cast<int>(n),
        static_cast<int>(capacity),
        vector<int>(static_cast<size_t>(n)),
        vector<Value>(static_cast<size_t>(n))
    };

    for (int i = 0; i < problem.itemCount; ++i) {
        long long volume = 0;
        long long value = 0;
        if (!(input >> volume >> value))
            throw runtime_error("Input error: expected n pairs volume_i value_i.");
        if (volume < 0 || volume > numeric_limits<int>::max())
            throw runtime_error("Input error: item volumes must be non-negative integers.");
        if (value < 0)
            throw runtime_error("Input error: item values must be non-negative integers.");
        problem.volume[i] = static_cast<int>(volume);
        problem.cost[i] = value;
    }

    string extra;
    if (input >> extra)
        throw runtime_error("Input error: unexpected data after the item list.");

    return problem;
}

Solution solveKnapsack(const Problem& problem) {
    const int n = problem.itemCount;
    const int B = problem.capacity;

    Solution solution;
    solution.optimum.assign(n + 1, vector<Value>(B + 1, 0));
    solution.take.assign(n + 1, vector<unsigned char>(B + 1, 0));

    for (int k = 1; k <= n; ++k) {
        const int volume = problem.volume[k - 1];
        const Value value = problem.cost[k - 1];
        for (int b = 0; b <= B; ++b) {
            const Value skip = solution.optimum[k - 1][b];
            solution.optimum[k][b] = skip;

            if (volume <= b) {
                const Value choose =
                    solution.optimum[k - 1][b - volume] + value;
                if (choose > skip) {
                    solution.optimum[k][b] = choose;
                    solution.take[k][b] = 1;
                }
            }
        }
    }

    int remaining = B;
    for (int k = n; k >= 1; --k) {
        if (!solution.take[k][remaining])
            continue;
        solution.selected.push_back(k);
        remaining -= problem.volume[k - 1];
        solution.usedCapacity += problem.volume[k - 1];
        solution.totalValue += problem.cost[k - 1];
    }
    reverse(solution.selected.begin(), solution.selected.end());
    return solution;
}

int main(int argc, char* argv[]) {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    bool detailed = false;
    string filename;
    for (int i = 1; i < argc; ++i) {
        const string argument = argv[i];
        if (argument == "--detailed") detailed = true;
        else if (filename.empty()) filename = argument;
        else {
            cerr << "Usage: " << argv[0]
                 << " [--detailed] [input_file]\n";
            return 2;
        }
    }

    ifstream inputFile;
    if (!filename.empty()) {
        inputFile.open(filename);
        if (!inputFile) {
            cerr << "Input error: cannot open file: " << filename << '\n';
            return 2;
        }
        cin.rdbuf(inputFile.rdbuf());
    }

    try {
        const Problem problem = readProblem(cin);
        const Solution solution = solveKnapsack(problem);
        cout << "Maximum value: "
             << solution.optimum[problem.itemCount][problem.capacity]
             << '\n';
        // В полном файле также находятся printTable и printResult.
    } catch (const exception& error) {
        cerr << error.what() << '\n';
        return 2;
    }
    return 0;
}

12. Короткий ответ для защиты

  1. Задача — выбрать неповторяющиеся предметы с максимальной суммарной ценностью при ограниченной вместимости.
  2. OPT(k,b) хранит лучший результат для первых k предметов и вместимости b.
  3. Для каждого состояния сравниваются два варианта: предмет не брать или взять.
  4. Таблица take хранит решение, принятое в каждой ячейке.
  5. После заполнения таблиц ответ равен OPT(n,B).
  6. Обратный ход по таблице take восстанавливает выбранные предметы.
  7. Сложность алгоритма — O(nB) по времени и памяти.
